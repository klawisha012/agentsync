# Публикацию создаёт только явная загрузка

Сохранение файла в домашней папке ИИ-агента публикацией не становится. Человек с подтверждённой почтой отдельно загружает одну домашнюю папку ИИ-агента, и эта загрузка создаёт одну новую публикацию. Старые публикации той же домашней папки ИИ-агента остаются. Без входа загрузить домашнюю папку ИИ-агента нельзя. Подтверждение почты для загрузки не нужно. Локальный агент при загрузке должен принадлежать тому же аккаунту, что и браузер.

## Considered Options

- Локальный агент сам загружает домашнюю папку ИИ-агента при каждой правке. Отклонено: страница менялась бы без решения человека, и каждая правка плодила бы публикацию.
