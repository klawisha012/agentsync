# Публикацию создаёт только явная загрузка

Сохранение файла в доме публикацией не становится. Человек с подтверждённой почтой отдельно загружает один дом, и эта загрузка создаёт одну новую публикацию. Старые публикации того же дома остаются. Без входа и без подтверждённой почты загрузить дом нельзя. Локальный агент при загрузке должен принадлежать тому же аккаунту, что и браузер.

## Considered Options

- Локальный агент сам загружает дом при каждой правке. Отклонено: страница менялась бы без решения человека, и каждая правка плодила бы публикацию.
