# Пустая переносимая настройка не публикуется

Если в доме нет переносимой настройки, загрузка не создаёт публикацию. Человек видит эту причину. Иначе точная замена пустой публикации стёрла бы переносимую настройку того, кто её применит. Учётные данные, кэши и машинные хуки переносимой настройкой не считаются.

## Considered Options

- Публиковать пустой дом. Отклонено: применение удалило бы чужие навыки, правила и плагины.
