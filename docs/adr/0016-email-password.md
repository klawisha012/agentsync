# Вход по почте и паролю

Аккаунт создаётся почтой и паролем. Имя страницы человек выбирает отдельно, почта именем не становится. Вход и имя есть до подтверждения письма. Письмо отмечает почту подтверждённой и не закрывает загрузку, снятие, смену имени, откат и применение. Забытый пароль меняется письмом на почту аккаунта. На странице аккаунта почта не показывается.

## Considered Options

- Одноразовая ссылка на почту. Отклонено.
- GitHub как единственный вход. Отклонено: имя страницы не должно зависеть от внешнего аккаунта.
