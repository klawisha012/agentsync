# Вход по почте и паролю

Аккаунт создаётся почтой и паролем. Имя страницы человек выбирает отдельно, почта именем не становится. Вход и имя есть до подтверждения письма. До письма закрыты только загрузка и снятие. Подтверждение машины, откат и применение своей публикации доступны сразу после входа. Забытый пароль меняется письмом на почту аккаунта. На странице аккаунта почта не показывается.

## Considered Options

- Одноразовая ссылка на почту. Отклонено.
- GitHub как единственный вход. Отклонено: имя страницы не должно зависеть от внешнего аккаунта.
