# Состояние сервера хранится в Postgres

Сервер держит аккаунты, публикации, лайки и просмотры в памяти процесса, и перезапуск их стирает. Это состояние переезжает в Postgres до тикета предпросмотра (#8). Цепочка и файлы компьютера остаются на машине, как в ADR 0010: в облаке только публикации.

В Postgres лежат аккаунт (почта, хеш пароля, имя, подтверждение почты), сессия на 14 суток, ссылка из письма на сутки, привязка машины (идентификатор компьютера, хост, слушатель, токен локального агента), публикация (постоянный адрес, ИИ-агент, номер, время, сжатое тело), лайк и просмотр вместе с тем, кто страницу уже открыл. На компьютере остаются цепочка, снимок перед применением, учётные данные ИИ-агента, его сессии, кэши, логи, память, история диалогов, машинный MCP, машинный хук и уже применённая настройка.

Тесты вызывают тот же HTTP. Сервер под ними говорит с Postgres, который тест поднимает в Docker. Compose поднимает тот же Postgres для обычного запуска. Схему сервер накатывает при старте. Второго хранилища в памяти нет.

## Considered Options

- Оставить память процесса. Отклонено: перезапуск стирает аккаунты, публикации, лайки, просмотры, сессии и уже выданные ссылки.
- Положить цепочку и снимок перед применением в Postgres. Отклонено: цепочка живёт на компьютере, в облаке только публикации.
- Держать для тестов второе хранилище в памяти. Отклонено: два пути разъедутся.
- Дописать предпросмотр и применение на памяти, потом перенести. Отклонено: это вторая переделка.
