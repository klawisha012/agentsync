# Чужое применение не требует совпадения аккаунтов

Если в браузере один аккаунт, а локальный агент компьютера подтверждён другим, чужую публикацию применить можно: файлы пишутся на этот компьютер. Загрузка, откат и применение своей публикации останавливаются. Человек видит пояснение, что аккаунты браузера и машины различаются. Инструкция загрузки подчиняется тому же правилу.

## Considered Options

- Останавливать и чужое применение, пока аккаунты не совпали. Отклонено: чужую публикацию применяют без входа.
- Создавать публикацию на аккаунте браузера из файлов чужой машины. Отклонено: загрузка читает дом только своего агента.
