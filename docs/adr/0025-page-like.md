# Лайк страницы один на аккаунт

Лайк отмечает страницу аккаунта, не публикацию. Его ставит вошедший аккаунт, по одному на страницу. Повторное нажатие снимает лайк. Свою страницу отметить нельзя. Подтверждённая почта для лайка не нужна.

## Considered Options

- Счётчик без входа, где каждое нажатие прибавляет единицу. Отклонено: его нельзя снять и легко накрутить.
- Лайк на каждую публикацию и сумма в списке. Отклонено: в списке одно число на страницу.
