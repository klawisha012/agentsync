# Удаление аккаунта повторяет пароль

Владелец удаляет аккаунт только после повторного ввода верного пароля. Без него аккаунт остаётся, человек видит пояснение. Подтверждённая почта для удаления не нужна. Публикации снимаются, имя освобождается, страница уходит из списка, лайки этого аккаунта снимаются с чужих страниц. Цепочки на дисках остаются и новому аккаунту не показываются. Машины, где публикации уже применены, не меняются.

## Considered Options

- Удалять сразу из уже открытого входа. Отклонено: одним нажатием снимаются все публикации.
