# Секрет в переносимом файле блокирует загрузку

Если переносимый файл содержит секрет, загрузка не создаёт публикацию. Человек видит, в каком файле секрет, и само значение в этом пояснении не показывается. Он убирает секрет и загружает дом снова. Снятие публикации для этого случая не используется: страница открыта всем, и секрет не должен успеть стать публичным. Учётные данные агента сюда не входят: их нет в переносимой настройке.

## Considered Options

- Публиковать файл как есть и полагаться на предпросмотр и снятие. Отклонено: снятие происходит после того, как секрет уже открыт.
