# У компьютера один аккаунт за раз

Новое подтверждение машины сменяет прежний аккаунт. Копии хранилищ лежат на диске раздельно по аккаунтам: новый владелец компьютера чужое хранилище не видит. Когда компьютер снова подтверждён прежним аккаунтом, его копия на месте. Владелец может снять подтверждение после входа. Агент перестаёт входить в аккаунт, хранилище аккаунта остаётся. Подтверждённая почта для подтверждения и снятия машины не нужна.

## Considered Options

- Закрепить компьютер за аккаунтом навсегда. Отклонено: машину можно передать другому аккаунту.
- Показывать одно хранилище компьютера любому подтверждённому аккаунту. Отклонено: в копии на диске лежат снимки прежнего владельца.
