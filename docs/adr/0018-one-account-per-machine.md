# У компьютера один аккаунт за раз

Новое подтверждение машины сменяет прежний аккаунт. Цепочки хранятся на диске раздельно по аккаунтам: новый владелец компьютера чужую цепочку не видит. Когда компьютер снова подтверждён прежним аккаунтом, его цепочка на месте. Владелец может снять подтверждение после входа. Агент перестаёт входить в аккаунт, цепочка на диске остаётся. Подтверждённая почта для подтверждения и снятия машины не нужна.

## Considered Options

- Закрепить компьютер за аккаунтом навсегда. Отклонено: машину можно передать другому аккаунту.
- Показывать одну цепочку компьютера любому подтверждённому аккаунту. Отклонено: в ней лежат незагруженные снимки прежнего владельца.
