# Канон `~/.agents/` — общая настройка, ИИ-агенты подключаются к нему ссылками

Общая настройка всех ИИ-агентов машины лежит в одном каталоге `~/.agents/` — каноне. Команда `agentsync <ИИ-агент> on` подключает ИИ-агента: элементы канона появляются в его домашней папке ссылками. Команда `off` убирает эти ссылки. На странице аккаунта карточки по ИИ-агентам остаются, у канона своя карточка, свой снимок и своё хранилище.

Снимок ИИ-агента разворачивает ссылки на канон в копии, поэтому один навык может быть в двух карточках. Применение публикации канона точно заменяет канон. Применение публикации ИИ-агента кладёт её элементы в канон: одноимённые элементы заменяются целиком, новые добавляются, остальные остаются. Затем этот ИИ-агент подключается. Перед изменением канон записывается в своё хранилище снимком перед применением.

Если имя элемента канона у ИИ-агента занято его собственной папкой или файлом, `on` сначала создаёт снимок ИИ-агента в его хранилище, затем ставит на это имя ссылку. Собственные элементы ИИ-агента с другими именами остаются у него и в канон не переходят.

MCP-сервер ссылкой не подключить: он лежит в общем файле ИИ-агента рядом с чужим состоянием, например в `~/.claude.json`. `on` вписывает серверы канона в этот файл в формате ИИ-агента, а машина помнит имена записей, которые вписала она. Повторный `on` убирает свою запись, которой в каноне больше нет. Одноимённую чужую запись `on` заменяет после снимка ИИ-агента. `off` удаляет только свои записи. Чужие записи с другими именами и прочие ключи файла не меняются. Учёт записей — состояние машины, в снимок и публикацию он не входит.

Отдельного понятия «приёмник» нет. ИИ-агент — любая программа из каталога ИИ-агентов, который поставляется с сервисом. `on`, `off` и установка навыка работают с любым ИИ-агентом каталога, а карточка появляется только после публикации. Имя в команде — имя из каталога или его синоним: `claude` и `claude-code` называют одну программу. Опубликовать по-прежнему можно папку с любым именем.

Это решение заменяет ADR 0035 и меняет ADR 0002 и ADR 0005 для публикации ИИ-агента: применение больше не точная замена его домашней папки.

## Considered Options

- Источник — домашняя папка одного ИИ-агента, навыки разводятся приёмникам (ADR 0035). Отклонено: у каждого ИИ-агента своя копия общей настройки, и копии расходятся.
- Единица публикации — только канон, без карточек ИИ-агентов. Отклонено: на странице остаются карточки по ИИ-агентам.
- Ссылки на канон в снимок ИИ-агента не входят. Отклонено: карточка ИИ-агента показывает всё, что он видит.
- Применение публикации ИИ-агента точно заменяет канон. Отклонено: применение карточки Claude убрало бы навыки, которые видит только Grok.
- Отказ, если в каноне уже есть одноимённый элемент. Отклонено: снимок перед применением уже защищает прежний элемент, отказ заставил бы удалять его вручную.
- Отказ `on`, если имя у ИИ-агента занято собственной папкой. Отклонено по той же причине: прежнюю папку возвращает откат.
- Оставить приёмник отдельным понятием и подключать только ИИ-агентов с карточкой. Отклонено: каталог приёмников в коде уже содержит `claude-code`, `codex` и `grok`, а Cursor без `on` не увидел бы канон.
- MCP как у dallay/agentsync в режиме `merge`: канон перекрывает одноимённые записи и ничего не удаляет. Отклонено: сервер, убранный из канона, оставался бы у ИИ-агента, а `off` его не убирал бы.
- MCP как у dallay/agentsync в режиме `overwrite`: раздел MCP становится точной копией канона. Отклонено: собственные серверы ИИ-агента пропадали бы.
- Первый `on` переносит все собственные элементы ИИ-агента в канон. Отклонено: личный навык одного ИИ-агента молча стал бы виден всем.

## Consequences

- Применение публикации ИИ-агента включает подключение. Кнопка чужой публикации меняет канон, а значит и все подключённые ИИ-агенты машины.
- Создание снимка ИИ-агента должно читать ссылку на каталог. Сейчас `readTree` на ней падает.
- Поиск ИИ-агентов сейчас пропускает `.agents`, а канону нужна своя карточка.
- Не решено: секрет в MCP канона; как хуки и плагины попадают в чужие форматы ИИ-агентов.
- Имя из поиска ИИ-агентов (`claude` из папки `.claude`) и slug каталога (`claude-code`) сейчас различаются, каталогу нужны синонимы.
