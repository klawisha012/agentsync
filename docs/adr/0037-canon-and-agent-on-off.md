# Канон `~/.agents/` — общая настройка, ИИ-агенты подключаются к нему ссылками

Общая настройка всех ИИ-агентов машины лежит в одном каталоге `~/.agents/` — каноне. Команда `agentsync <ИИ-агент> on` подключает ИИ-агента: элементы канона появляются в его домашней папке ссылками. Команда `off` убирает эти ссылки. На странице аккаунта карточки по ИИ-агентам остаются, у канона своя карточка, свой снимок и своё хранилище.

Снимок ИИ-агента разворачивает ссылки на канон в копии, поэтому один навык может быть в двух карточках. Применение публикации канона точно заменяет канон. Применение публикации ИИ-агента кладёт её элементы в канон: одноимённые элементы заменяются целиком, новые добавляются, остальные остаются. Затем этот ИИ-агент подключается. Перед изменением канон записывается в своё хранилище снимком перед применением.

Это решение заменяет ADR 0035 и меняет ADR 0002 и ADR 0005 для публикации ИИ-агента: применение больше не точная замена его домашней папки.

## Considered Options

- Источник — домашняя папка одного ИИ-агента, навыки разводятся приёмникам (ADR 0035). Отклонено: у каждого ИИ-агента своя копия общей настройки, и копии расходятся.
- Единица публикации — только канон, без карточек ИИ-агентов. Отклонено: на странице остаются карточки по ИИ-агентам.
- Ссылки на канон в снимок ИИ-агента не входят. Отклонено: карточка ИИ-агента показывает всё, что он видит.
- Применение публикации ИИ-агента точно заменяет канон. Отклонено: применение карточки Claude убрало бы навыки, которые видит только Grok.
- Отказ, если в каноне уже есть одноимённый элемент. Отклонено: снимок перед применением уже защищает прежний элемент, отказ заставил бы удалять его вручную.

## Consequences

- Применение публикации ИИ-агента включает подключение. Кнопка чужой публикации меняет канон, а значит и все подключённые ИИ-агенты машины.
- Создание снимка ИИ-агента должно читать ссылку на каталог. Сейчас `readTree` на ней падает.
- Поиск ИИ-агентов сейчас пропускает `.agents`, а канону нужна своя карточка.
- Не решено: что `on` делает с файлом ИИ-агента, который занимает имя элемента канона; как MCP, хуки и плагины попадают в чужие форматы ИИ-агентов; подключаются ли приёмники.
