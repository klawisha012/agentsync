# Машину подтверждают на сайте

Инструкция установки доводит локальный агент до входа и останавливается на подтверждении машины. Человек подтверждает машину на сайте, после этого агент входит в аккаунт. Пароль аккаунта в инструкцию не входит.

## Considered Options

- Код, который человек переносит в локальный агент. Отклонено в пользу подтверждения на сайте.
- Передавать пароль локальному агенту. Отклонено: инструкция установки не должна содержать пароль.
