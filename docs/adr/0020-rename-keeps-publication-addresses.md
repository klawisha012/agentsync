# Смена имени не меняет адрес публикации

После подтверждения почты имя можно сменить. Страница аккаунта открывается по новому имени. Адрес каждой публикации постоянный и от имени не зависит.

## Considered Options

- Сделать имя постоянным. Отклонено: имя можно опечатать, а публикация уже могла быть применена по своему адресу.
