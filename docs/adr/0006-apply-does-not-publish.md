# Применение не создаёт публикацию

Снимок перед применением пишется на машину и в облако не уходит. Применение не меняет страницу применяющего и не создаёт публикацию. Страница аккаунта меняется только когда этот аккаунт сам загружает дом. Откат к состоянию до применения возможен на той машине, где применение произошло.

## Considered Options

- Загружать снимок перед применением. Отклонено: загрузка сразу стала бы публикацией и сменила бы кнопку дома.
- Считать результатом применения новую публикацию применяющего. Отклонено: иначе чужая настройка публикуется под его именем без отдельной загрузки.
