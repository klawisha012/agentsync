# Применение не создаёт публикацию

Применение не меняет страницу применяющего и не создаёт публикацию. Снимок перед применением пишется в хранилище аккаунта и публикацией не становится. Куда девается этот снимок и как устроен откат, решает ADR 0034. Страница аккаунта меняется, только когда этот аккаунт сам загружает снимок.

## Considered Options

- Загружать снимок перед применением как публикацию. Отклонено: страница применяющего менялась бы без отдельной загрузки.
- Считать результатом применения новую публикацию применяющего. Отклонено: иначе чужая настройка публикуется под его именем без отдельной загрузки.
