# Имя уникально без учёта регистра

Имя страницы выбирает человек. В нём от 3 до 32 знаков: буквы любого алфавита, цифры и дефис, дефис не стоит по краям. Пробелов нет. `Alice` и `alice` — одно имя, потому что поиск не различает регистр. Буквы разных алфавитов, даже похожие на вид, остаются разными именами. Имена страниц самого сайта занять нельзя. Почта на странице не показывается.

## Considered Options

- Считать уникальность посимвольной, оставляя `Alice` и `alice` разными страницами. Отклонено: поиск показал бы две неразличимые страницы.
