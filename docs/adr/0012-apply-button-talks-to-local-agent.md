# Кнопка применения говорит с агентом этого компьютера

Кнопка применения на странице чужой публикации отдаёт команду локальному агенту того компьютера, где открыта страница. Вход на сайт для чужой публикации не нужен. Свою публикацию применяют после входа. Если агент не отвечает, кнопки нет и остаётся инструкция применения. Применение выполняется на машине этого агента. Страницы автора и применяющего от этого не меняются.

## Considered Options

- Требовать вход и для чужой публикации. Отклонено: без входа можно применить чужой снимок.
