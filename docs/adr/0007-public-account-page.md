# Страница аккаунта открыта по выбранному имени

Человек сам выбирает уникальное имя. Страница аккаунта и предпросмотр любой неснённой публикации открываются по этому имени без входа в сервис. Применение по-прежнему выполняет машина, а не браузер.

## Considered Options

- Прятать страницу и предпросмотр за входом в сервис. Отклонено: публикацию можно посмотреть до установки локального агента.
