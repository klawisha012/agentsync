# Применение разовое

Публикация — это снимок на момент публикации. Применение один раз заменяет переносимую настройку дома этой публикацией и перед этим сохраняет снимок применяющего. Следующие публикации автора сами на машину не приходят. Так кнопка на сайте остаётся явным действием, а не подпиской.
