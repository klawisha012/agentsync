# Содержимое публикации не модерируется

Загрузка становится публикацией сразу. Кроме секрета в переносимом файле, пустой переносимой настройки и машинных MCP и хуков, сервис содержимое не проверяет. Разрушительная инструкция внутри навыка публикацию не блокирует. Перед применением файлы видны в предпросмотре.

## Considered Options

- Выпускать публикацию только после проверки сервисом. Отклонено: загрузка и есть публикация, решение остаётся за тем, кто смотрит предпросмотр.
