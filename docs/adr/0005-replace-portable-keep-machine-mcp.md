# Применение заменяет переносимое и оставляет машинное

Переносимая настройка дома после применения совпадает с публикацией. Одинаковый навык заменяется навыком из публикации. Файл, который был только у применяющего, с дома уходит и остаётся в снимке перед применением. Машинный MCP в публикацию не входит, машинный MCP применяющего остаётся на месте. Абсолютные пути, секретные заголовки и токены окружения не копируются. Поставка продукта и кэши в публикацию не входят и при применении не меняются. Предпросмотр показывает ровно содержимое публикации.

## Considered Options

- Слить навыки Алисы с навыками Боба и оставить его лишние файлы. Отклонено: применение делает переносимую настройку точной копией публикации, лишнее остаётся только в снимке перед применением.
- Копировать MCP как есть, вместе с абсолютными путями и токенами. Отклонено: такой MCP привязан к чужой машине и чужому секрету.
