# Цепочка снимков хранится на машине целиком

Каждое применение дописывает снимок перед применением в цепочку этого дома на этой машине. Откат возвращает дом к последнему снимку и убирает его из цепочки. Цепочка не обрезается: исходная настройка может быть самым ранним снимком и в облако не загружалась. Другая машина того же аккаунта этой цепочки не видит. На странице аккаунта цепочку показывает только вошедшему владельцу и только с того компьютера, чей локальный агент принадлежит ему. Откат берёт последний снимок этой цепочки и публикации не меняет.

## Considered Options

- Хранить только последний снимок. Отклонено: второе применение уничтожило бы единственную локальную копию исходной настройки.
- Хранить снимок перед применением в аккаунте как частную копию. Отклонено: в облаке остаются только публикации, незагруженная правка не становится чужой кнопкой.
