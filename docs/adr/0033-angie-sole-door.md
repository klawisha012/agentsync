# Снаружи слушает только Angie

Браузер открывал сайт на порту 3000, API был опубликован на 8080, а сайт сам пересылал `/backend` и `/agent-bridge`. Дверь одна: Angie. Порты 3000 и 8080 с хоста сняты. Postgres на 5432 остаётся.

Порт 80 переводит на https://zwarder.ru. Порт 443 отдаёт сайт. Страницы идут в Next. Префикс `/api` Angie срезает и отдаёт остаток Echo. `/agent-bridge/` срезается и уходит локальному агенту на этой машине. Пересылки из Next нет.

Снаружи установка лежит на `/api/cli/…`, применение на `/api/apply/…`. На Echo применение слушает `/apply/…`: срез снимает `/api`, а старый путь `/api/apply/…` с ним столкнулся бы. Сертификат на имя zwarder.ru выпускает и продлевает Angie у Let's Encrypt проверкой по HTTP. Ключ в git не кладём. `WEB_ORIGIN` равен https://zwarder.ru. Angie передаёт `X-Forwarded-Proto: https`, чтобы кука сессии стала защищённой.

## Considered Options

- Оставить пересылку в Next и поставить Angie только перед сайтом. Отклонено: два опубликованных порта обходят Angie, а адрес API уже ломался, потому что был зашит при сборке.
- Самоподписанный сертификат на localhost. Отклонено: дверь открывается по имени zwarder.ru.
- Поднять дверь на прежнем адресе DNS `188.187.212.167`. Отклонено: запись A указывает на этот компьютер, `80.72.24.108`.
- Включить в сертификат `www.zwarder.ru`. Отклонено: такой записи в DNS нет.
