# Поиск без учёта регистра и с живым списком

Поиск в списке аккаунтов ищет текст имени без учёта регистра, по вхождению набранных символов. Текст файлов публикаций не ищется. С первого введённого символа под строкой открыт выпадающий список аккаунтов, и каждый новый символ его обновляет. Пустая строка показывает весь список, без выпадающего списка. Отдельной кнопки поиска нет.

## Considered Options

- Искать ещё и текст файлов публикаций. Отклонено: в выдаче только аккаунты по имени.
