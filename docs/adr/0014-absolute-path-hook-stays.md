# Хук с абсолютным путём остаётся на машине

Хук, в команде которого есть абсолютный путь, в публикацию не входит. Не входит и скрипт, на который этот хук ссылается. При применении машинные хуки машины сохраняются. Хук без абсолютного пути остаётся переносимой настройкой и заменяется вместе с ней.

## Considered Options

- Переносить скрипт из домашней папки ИИ-агента и переписывать путь на домашнюю папку ИИ-агента применяющего. Отклонено.
- Копировать команду вместе с чужим абсолютным путём. Отклонено: хук смотрел бы в чужую домашнюю папку ИИ-агента.
