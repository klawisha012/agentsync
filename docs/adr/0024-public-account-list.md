# Список аккаунтов открыт всем

Есть общий список всех аккаунтов и поиск по нему. В списке видны число просмотров страницы аккаунта и число лайков этой страницы. Отдельного лайка у публикации нет. По умолчанию список упорядочен по лайкам по убыванию. При равенстве выше число просмотров, затем имя. Его можно пересортировать по просмотрам, по имени и по времени последней публикации. Аккаунт без публикации при сортировке по времени идёт последним.

## Considered Options

- Открывать страницу только по точному имени или ссылке. Отклонено.
- Искать по имени, но не показывать общий список. Отклонено: список есть, поиск есть вместе с ним.
