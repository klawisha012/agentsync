# Удаление аккаунта снимает публикации и освобождает имя

Владелец может удалить аккаунт. Все его публикации становятся снятыми, имя можно занять снова. Машины, где публикации уже применены, не меняются. Цепочки остаются на дисках компьютеров и аккаунту, созданному заново, не показываются. Новый вход с той же почтой — новый аккаунт.

## Considered Options

- Запретить удаление и оставить только поштучное снятие. Отклонено: имя и страница не должны пережить аккаунт.
