# Установка навыка не требует входа

`agentsync skills` читает ту же версию, что страница версии. Вход не нужен: открытую версию команда копирует без сессии и без токена. Скрытую версию без входа команда не копирует. Сессия владельца или подтверждённая машина владельца эту версию открывают. Правило входа для своей публикации остаётся у применения и на установку не действует.

## Considered Options

- Читать версию через применение. Отклонено: применение без входа останавливается, а свою публикацию применяет только сессия браузера.
- Отдавать скрытую версию всем. Отклонено: номер версии короткий, и файлы ушли бы без открытия страницы.
