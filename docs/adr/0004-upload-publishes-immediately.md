# Загрузка сразу публикует и не стирает прошлые

Отдельного скрытого снимка в облаке нет. Любая загрузка домашней папки ИИ-агента сразу становится публикацией на странице аккаунта. Новая загрузка той же домашней папки ИИ-агента не удаляет прежние публикации. Кнопка ИИ-агента применяет последнюю. Машины, которые уже применили старую публикацию, от новой сами не меняются.

## Considered Options

- Сначала частный снимок, публикация отдельным действием. Отклонено: загрузка и есть публикация.
- Новая загрузка заменяет прежнюю публикацию той же домашней папки ИИ-агента. Отклонено: публикация остаётся снимком на свой момент, старую всё ещё можно открыть и применить.
