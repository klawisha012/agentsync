# Установка агента и применение — разные инструкции

Браузер не пишет в дом. Кнопка на сайте отдаёт команду локальному агенту, который уже вошёл в аккаунт. Для агента на машине на сайте две разные инструкции, и одна не делает работу другой. Инструкция установки одна на весь сайт и ставит локальный агент. Инструкция применения своя у каждой публикации и применяет только её через уже установленный локальный агент. Если локального агента нет, инструкция применения переходит к инструкции установки и сама в дом не пишет.
