# Один посетитель даёт один просмотр за всё время

Владелец страницы просмотр не добавляет. Браузер без входа добавляет не больше одного. Вход с этого браузера привязывает уже засчитанный просмотр к аккаунту и второй не добавляет. Другой компьютер того же аккаунта тоже не добавляет просмотр. Повторное открытие и предпросмотр публикации в счётчик не входят. Лайк по-прежнему ставит только вошедший аккаунт.

## Considered Options

- Считать каждое открытие снова. Отклонено: у одного человека не больше одного просмотра за всё время.
- Считать браузер без входа и последующий вход как два просмотра. Отклонено.
