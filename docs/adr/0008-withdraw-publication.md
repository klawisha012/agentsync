# Публикацию можно снять

Автор с подтверждённой почтой может снять одну публикацию. Локальный агент для снятия не нужен. После снятия её нельзя открыть и нельзя применить заново. Машины, где она уже применена, не меняются. Кнопка дома переходит на предыдущую оставшуюся публикацию этого дома. Если оставшихся нет, кнопки применения у дома нет.

## Considered Options

- Оставлять публикацию навсегда. Отклонено: загрузка сразу видна всем, автору нужен способ остановить дальнейшую раздачу.
