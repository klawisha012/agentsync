# Публикацию можно снять

Автор после входа может снять одну публикацию. Подтверждение почты для снятия не нужно. Локальный агент для снятия не нужен. После снятия её нельзя открыть и нельзя применить заново. Машины, где она уже применена, не меняются. Кнопка ИИ-агента переходит на предыдущую оставшуюся публикацию этого ИИ-агента. Если оставшихся нет, кнопки применения у этого ИИ-агента нет.

## Considered Options

- Оставлять публикацию навсегда. Отклонено: загрузка сразу видна всем, автору нужен способ остановить дальнейшую раздачу.
