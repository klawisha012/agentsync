# Выбранные элементы версии ложатся в agents, команды skills нет

Единственная точка входа настройки на машине — `~/.agents`. Команда `agentsync skills` копировала навыки прямо в каталоги ИИ-агентов, мимо agents. Её больше нет. Вместо неё `agentsync apply <автор> <ИИ-агент> --version <номер> <путь>…` кладёт в agents только названные файлы и папки одной версии. Папка с `SKILL.md` становится `skills/<имя>`. Субагенты, команды, файл инструкций и записи MCP, плагинов и хуков разбираются по тем же местам каталога ИИ-агентов, что и при полном применении. Файл, который не даёт agents ничего, пропускается, и вывод его называет. Перед записью agents уходит в снимок, затем подключённые ИИ-агенты подключаются заново. Сайт собирает эту команду из всех элементов, отмеченных на странице версии.

Правило входа из ADR-0036 остаётся: открытую версию команда берёт без входа, скрытую — с сессией владельца или токеном его машины.

Архивы и установщики (`.zip`, `.rar`, `.7z`, `.tar`, `.gz`, `.tgz`, `.bz2`, `.xz`, `.zst`, `.exe`, `.msi`, `.dmg`, `.iso`) не являются настройкой ИИ-агента. Они остаются на машине, как `.env` и логи: в снимок и публикацию не входят.

## Considered Options

- Оставить `agentsync skills` рядом. Отклонено: две дороги для навыков, одна из них мимо agents.
- Новая команда `agentsync add`. Отклонено: выборочное применение — то же применение, разбор карточки общий.
- Выбор ИИ-агентов и места (`--into`, `--global`, `--project`). Отклонено: подключение к agents уже доводит элемент до каждого подключённого ИИ-агента.
