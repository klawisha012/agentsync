# AgentSync

Сервис, в котором загрузка ИИ-агента сразу становится публикацией на странице аккаунта, а другой аккаунт разово применяет её у себя.

## Участники

**Аккаунт**:
Человек в сервисе. Ему принадлежат его публикации, и локальный агент входит именно в аккаунт.
_Avoid_: пользователь, авторизация

**Имя**:
Публичное имя страницы, уникальное без учёта регистра: 3–32 знака из букв любого алфавита, цифр и дефиса не по краям. Имена страниц самого сайта заняты. Похожие буквы разных алфавитов остаются разными именами. После подтверждения почты имя можно сменить, адреса публикаций от этого не меняются, почта на странице не показывается.
_Avoid_: логин, ник, email

**Страница аккаунта**:
Место, где видны публикации аккаунта. У каждого ИИ-агента одна кнопка применения последней публикации. Прежние публикации можно открыть отдельно. Предпросмотр открывается без входа в сервис.
_Avoid_: профиль, лента, черновик

**Список аккаунтов**:
Общий перечень всех аккаунтов. В нём есть поиск, число просмотров страницы и число лайков страницы. По умолчанию выше лайки. При равенстве выше просмотры, затем имя. Список можно пересортировать по просмотрам, по имени и по времени последней публикации. Аккаунт без публикации в сортировке по времени идёт последним.
_Avoid_: каталог, лента, профиль

**Поиск**:
Строка списка аккаунтов. Ищет имя как текст: без учёта регистра, по вхождению набранных символов. Текст файлов публикаций не ищет. С первого символа под строкой открыт выпадающий список аккаунтов, и он обновляется на каждый новый символ. Пустая строка показывает весь список без выпадающего списка.
_Avoid_: точный поиск, поиск по файлам, поиск по кнопке

**Просмотр**:
Один человек даёт чужой странице один просмотр за всё время. Браузер без входа считает его один раз. Вход с этого браузера привязывает просмотр к аккаунту и второй не добавляет, в том числе с другого компьютера. Владелец, повторное открытие и предпросмотр публикации счётчик не увеличивают.
_Avoid_: предпросмотр, просмотр публикации, лайк

**Лайк**:
Отметка чужой страницы аккаунта вошедшим аккаунтом. На страницу приходится один лайк аккаунта. Повторное нажатие снимает лайк. Свою страницу отметить нельзя. Подтверждённая почта не нужна.
_Avoid_: избранное, плюс, лайк публикации

**Локальный агент**:
Программа на машине аккаунта, которая загружает ИИ-агентов и применяет публикации.
_Avoid_: демон, клиент, CLI, ИИ-агент

**Подтверждение машины**:
Действие человека на сайте после входа, после которого локальный агент входит в его аккаунт. У компьютера один аккаунт за раз: новое подтверждение сменяет прежнее. Цепочка прежнего аккаунта остаётся на диске и новому не показывается.
_Avoid_: пароль, код, токен

**Снятие машины**:
Действие владельца после входа. Локальный агент перестаёт входить в аккаунт. Цепочка на диске остаётся. Подтверждённая почта для этого не нужна.
_Avoid_: удаление аккаунта, откат

## Содержимое

**ИИ-агент**:
Любой именованный агент, чью переносимую настройку публикуют и применяют отдельно от остальных. Набор не закрыт: Grok, Agents и Claude только примеры.
_Avoid_: дом, папка, бандл, агент

**Переносимая настройка**:
Часть ИИ-агента, которая задаёт его поведение: конфиг, хуки без абсолютного пути, тема, включённые плагины, правила, навыки, плагины и MCP, кроме машинного MCP и машинного хука.
_Avoid_: полная папка, конфиг

**Машинный MCP**:
MCP, привязанный к конкретной машине или к секрету: абсолютный путь, секретный заголовок, токен в окружении. В публикацию не входит. При применении такой MCP на машине остаётся.
_Avoid_: MCP

**Машинный хук**:
Хук, в команде которого есть абсолютный путь. В публикацию не входит ни хук, ни скрипт, на который он ссылается. При применении машинные хуки этой машины остаются.
_Avoid_: хук, машинный MCP

**Поставка**:
Файлы, которые приходят вместе с установкой продукта, и их кэши. В публикацию не входят и при применении не меняются.
_Avoid_: настройка, ИИ-агент

**Учётные данные**:
Вход владельца в сам ИИ-агент на этой машине. В публикацию не входят и при применении не перезаписываются.
_Avoid_: авторизация, токен, сессия, секрет

**Секрет**:
Значение внутри переносимого файла, которое даёт доступ к чужому ресурсу. Пока секрет лежит в файле, загрузка не становится публикацией.
_Avoid_: учётные данные

**Снимок**:
Копия переносимой настройки одного ИИ-агента на момент снятия.
_Avoid_: бэкап, бандл, архив

**Снимок перед применением**:
Снимок переносимой настройки ИИ-агента, записанный на машину непосредственно перед применением. В облако не загружается и публикацией не становится.
_Avoid_: бэкап, публикация

**Цепочка**:
Снимки перед применением одного ИИ-агента на одной машине, от позднего к раннему. Хранится на этой машине целиком и в облако не уходит. На странице аккаунта её видит только вошедший владелец, и только когда локальный агент этого компьютера принадлежит ему.
_Avoid_: история публикаций, облачный бэкап, профиль

**Публикация**:
Снимок одного ИИ-агента, созданный загрузкой и сразу видимый на странице аккаунта. У неё постоянный адрес. Новая загрузка того же ИИ-агента прежние публикации не удаляет.
_Avoid_: черновик, синхронизация, шаринг, пресет

## Действия

**Подтверждённая почта**:
Почта аккаунта, которую человек подтвердил по письму. Пока почта не подтверждена, недоступны только загрузка и снятие. Подтверждение машины, откат и применение своей публикации от письма не зависят.
_Avoid_: вход, имя

**Загрузка**:
Явное действие над одним ИИ-агентом. Нужны подтверждённая почта и локальный агент этого же аккаунта на компьютере. Создаёт одну новую публикацию. Правка файла сама по себе загрузку не вызывает.
_Avoid_: применение, синхронизация, автосохранение

**Пояснение**:
Текст человеку, когда действие не выполнено. Называет причину. Значение секрета в текст не входит.
_Avoid_: ошибка

**Отказ загрузки**:
Загрузка, которая не стала публикацией. Пояснение называет причину: нет переносимой настройки, секрет в названном файле, почта не подтверждена или аккаунт браузера не совпал с аккаунтом машины.
_Avoid_: ошибка

**Применение**:
Разовая точная замена переносимой настройки одного ИИ-агента публикацией. Файл, которого в публикации нет, уходит из ИИ-агента и остаётся в снимке перед применением. Машинный MCP, машинный хук, учётные данные и поставка остаются. Если запись обрывается, переносимая настройка возвращается к состоянию до попытки, снимок попытки в цепочку не попадает, человек видит пояснение. Страница применяющего не меняется. Поздние публикации автора сами на машину не приходят.
_Avoid_: слияние, синхронизация, деплой, подписка

**Кнопка применения**:
Команда на странице публикации. Её выполняет локальный агент компьютера, где открыта страница. Без входа она применяет только чужую публикацию. Свою публикацию применяют после входа. Если локальный агент не отвечает, остаётся инструкция применения.
_Avoid_: инструкция применения

**Откат**:
Возврат одного ИИ-агента на этой машине к последнему снимку цепочки. Этот снимок из цепочки уходит. Делается со страницы аккаунта после входа, когда локальный агент компьютера принадлежит этому аккаунту. Публикации не меняет.
_Avoid_: снятие, применение

**Снятие**:
Действие автора над одной публикацией после входа и подтверждения почты. Локальный агент для него не нужен. После снятия публикацию нельзя открыть и нельзя применить заново. Машины, где она уже применена, остаются как есть. Кнопка ИИ-агента переходит на предыдущую оставшуюся публикацию этого ИИ-агента. Если её нет, кнопки применения у этого ИИ-агента нет.
_Avoid_: удаление аккаунта, откат

**Предпросмотр**:
Содержимое публикации до применения. Совпадает с тем, что применение изменит в переносимой настройке. Доступен без входа в сервис. Машинных хуков и машинного MCP там нет.
_Avoid_: дифф

**Инструкция установки**:
Одна страница сайта, по которой ИИ-агент ставит локальный агент и доводит его до подтверждения машины. Публикацию не применяет и ИИ-агента не загружает.
_Avoid_: инструкция применения

**Инструкция применения**:
Страница одной публикации. Чужую публикацию ИИ-агент применяет через локальный агент без входа в браузер. Свою публикацию инструкция применяет только когда в браузере открыт этот аккаунт, иначе останавливается с пояснением. Если локального агента нет, выполнение переходит к инструкции установки и ИИ-агента не изменяет.
_Avoid_: инструкция установки, инструкция загрузки

**Удаление аккаунта**:
Действие владельца, которое проходит только после повторного верного пароля. Публикации снимаются, имя освобождается, страница уходит из списка, лайки этого аккаунта снимаются с чужих страниц. Подтверждённая почта не нужна. Цепочки на дисках и уже применённые чужие машины остаются как были.
_Avoid_: снятие, снятие машины

**Инструкция загрузки**:
Страница сайта, где каждый ИИ-агент назван отдельно. По ней ИИ-агент загружает названного через локальный агент. Если локального агента нет, выполнение переходит к инструкции установки.
_Avoid_: инструкция применения, инструкция установки
