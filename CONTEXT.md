# AgentSync

Сервис, в котором снимок ИИ-агента или канона лежит в частном хранилище, загрузка делает снимок публикацией, а другой аккаунт разово применяет её у себя.

## Участники

**Аккаунт**:
Человек в сервисе. Ему принадлежат его публикации, и локальный агент входит именно в аккаунт.
_Avoid_: пользователь, авторизация

**Имя**:
Публичное имя страницы, уникальное без учёта регистра: 3–32 знака из букв любого алфавита, цифр и дефиса не по краям. Имена страниц самого сайта заняты. Похожие буквы разных алфавитов остаются разными именами. После входа имя можно сменить, адреса публикаций от этого не меняются, почта на странице не показывается.
_Avoid_: логин, ник, email

**Страница аккаунта**:
Место, где видны публикации аккаунта. Карточка есть у канона и у каждого ИИ-агента, чья публикация открыта. У карточки одна кнопка применения последней публикации. Прежние публикации можно открыть отдельно. Предпросмотр открывается без входа в сервис.
_Avoid_: профиль, лента, черновик

**Список аккаунтов**:
Общий перечень всех аккаунтов. В нём есть поиск, число просмотров страницы и число лайков страницы. Набор имён ИИ-агентов там не объявлен. По умолчанию выше лайки. При равенстве выше просмотры, затем имя. Список можно пересортировать по просмотрам, по имени и по времени последней публикации. Аккаунт без публикации в сортировке по времени идёт последним.
_Avoid_: каталог, лента, профиль

**Поиск**:
Строка списка аккаунтов. Ищет имя как текст: без учёта регистра, по вхождению набранных символов. Текст файлов публикаций не ищет. С первого символа под строкой открыт выпадающий список аккаунтов, и он обновляется на каждый новый символ. Пустая строка показывает весь список без выпадающего списка.
_Avoid_: точный поиск, поиск по файлам, поиск по кнопке

**Просмотр**:
Один человек даёт чужой странице один просмотр за всё время. Браузер без входа считает его один раз. Вход с этого браузера привязывает просмотр к аккаунту и второй не добавляет, в том числе с другого компьютера. Владелец, повторное открытие и предпросмотр публикации счётчик не увеличивают.
_Avoid_: предпросмотр, просмотр публикации, лайк

**Лайк**:
Отметка чужой страницы аккаунта вошедшим аккаунтом. На страницу приходится один лайк аккаунта. Повторное нажатие снимает лайк. Свою страницу отметить нельзя.
_Avoid_: избранное, плюс, лайк публикации

**Локальный агент**:
Программа `agentsync` на машине аккаунта. Создаёт снимки, загружает их как публикации, применяет публикации, подключает и отключает ИИ-агентов.
_Avoid_: демон, клиент, CLI, ИИ-агент

**Подтверждение машины**:
Действие человека на сайте после входа, после которого локальный агент входит в его аккаунт. У компьютера один аккаунт за раз: новое подтверждение сменяет прежнее. Копия хранилища прежнего аккаунта остаётся на диске и новому не показывается.
_Avoid_: пароль, код, токен

**Снятие подтверждения машины**:
Действие владельца после входа. Локальный агент перестаёт входить в аккаунт. Хранилище аккаунта остаётся.
_Avoid_: снятие публикации, удаление аккаунта, откат

## Содержимое

**ИИ-агент**:
Программа для работы с ИИ, чью переносимую настройку публикуют и применяют отдельно от остальных. Опубликовать можно папку с любым именем. Подключение, отключение и установка навыка работают только с ИИ-агентом из каталога ИИ-агентов. Карточка на странице аккаунта есть только у ИИ-агента с открытой публикацией.
_Avoid_: приёмник, дом, ИИ-дом, папка, бандл, агент

**Каталог ИИ-агентов**:
Список ИИ-агентов, который поставляется вместе с сервисом. Для каждого называет имя, синонимы имени и места на машине, куда ложатся навыки и другие элементы канона. Для каждого вида элементов называет, как ИИ-агент его получает: ссылкой, когда формат совпадает с форматом канона, переводом в формат ИИ-агента или никак. Синоним — то же ИИ-агент: `claude` и `claude-code` называют одну программу.
_Avoid_: каталог приёмников, список аккаунтов

**Домашняя папка ИИ-агента**:
Каталог на машине, в котором лежат файлы одного ИИ-агента. Переносимая настройка — только часть этой папки.
_Avoid_: дом, ИИ-дом

**Канон**:
Каталог `~/.agents/` на машине: общая настройка, которую видят все подключённые ИИ-агенты. Снимок канона создаётся, загружается и применяется отдельно от ИИ-агентов, на странице аккаунта у него своя карточка. Снимок ИИ-агента содержит копии файлов канона, которые этот ИИ-агент видит, поэтому один навык может быть в двух карточках. В снимке ИИ-агента элементы канона отмечены отдельно от его собственных файлов.
_Avoid_: .agents, общий каталог, источник правды

**Элемент канона**:
Наименьшая часть канона, которую применение заменяет целиком: папка навыка, файл субагента, файл пользовательской команды, хук, запись MCP-сервера, запись плагина, файл инструкций. У каждого вида элементов в каноне один формат.
_Avoid_: файл, единица

**Субагент**:
Файл с описанием отдельного помощника, которого ИИ-агент вызывает для подзадачи, например `go-developer.md`.
_Avoid_: агент, ИИ-агент, локальный агент

**Файл инструкций**:
Общие правила для всех ИИ-агентов: `~/.agents/AGENTS.md`. Подключённый ИИ-агент видит его ссылкой под своим именем: `CLAUDE.md`, `AGENTS.md`, `GEMINI.md`. Применение заменяет его целиком.
_Avoid_: правила, промпт, CLAUDE.md

**Плагин**:
Пакет из маркетплейса, который ИИ-агент скачивает сам. В каноне лежит только запись плагина: источник маркетплейса, имя плагина и признак включения. Файлы плагина и клоны маркетплейсов в канон и в снимок не входят. Навыки и хуки внутри плагина элементами канона не становятся.
_Avoid_: навык, расширение, маркетплейс

**Пользовательская команда**:
Файл с текстом, который ИИ-агент выполняет по вызову `/имя`.
_Avoid_: команда agentsync, промпт

**Переносимая настройка**:
Часть домашней папки ИИ-агента, которая задаёт его поведение: конфиг, хуки без абсолютного пути, тема, включённые плагины, правила, навыки, плагины и MCP, кроме машинного MCP и машинного хука.
_Avoid_: домашняя папка ИИ-агента, конфиг

**Машинный MCP**:
MCP-сервер, привязанный к конкретной машине абсолютным путём. Решается по серверу, а не по файлу: соседние серверы того же файла в публикацию входят. В публикацию не входит. При применении такой сервер на машине остаётся.
_Avoid_: MCP

**Переменная секрета**:
Имя вместо значения секрета в переносимом файле, например `${GITHUB_TOKEN}`. Значение лежит на машине: в окружении или в `~/.agents/.env`, и в снимок не входит. Получатель публикации кладёт своё значение у себя.
_Avoid_: ссылка, токен, секрет

**Машинный хук**:
Хук, в команде которого есть абсолютный путь. В публикацию не входит ни хук, ни скрипт, на который он ссылается. При применении машинные хуки этой машины остаются.
_Avoid_: хук, машинный MCP

**Коннектор**:
Частная интеграция под одну задачу, отдельно от MCP и от плагина. В подключение не входит.
_Avoid_: MCP, плагин

**Файлы программы**:
Файлы, которые приходят вместе с установкой самого ИИ-агента, и их кэши. В публикацию не входят и при применении не меняются.
_Avoid_: поставка, настройка, ИИ-агент

**Учётные данные**:
Вход владельца в сам ИИ-агент на этой машине. В публикацию не входят и при применении не перезаписываются.
_Avoid_: авторизация, токен, сессия, секрет

**Секрет**:
Значение внутри переносимого файла, которое даёт доступ к чужому ресурсу. Пока секрет лежит в файле, снимок не создаётся и публикация из него не появляется. Переменная секрета секретом не считается.
_Avoid_: учётные данные

**Снимок**:
Копия переносимой настройки одного ИИ-агента или канона на момент создания. В хранилище снимок неизменяем.
_Avoid_: бэкап, бандл, архив, коммит, цепочка

**Хранилище**:
Частная история снимков одного ИИ-агента или канона одного аккаунта. Другой аккаунт его не открывает и не применяет. На странице аккаунта его видит только вошедший владелец. Снимки остаются. На другую машину того же аккаунта само не приходит. Файлы там меняет только явное применение выбранного снимка.
_Avoid_: цепочка, репозиторий, git, синхронизация, черновик, облачный бэкап

**Текущий снимок**:
Снимок хранилища, с которым сейчас сверяется настройка на машине. Создание снимка делает текущим новый снимок.
_Avoid_: текущая метка, голова, ветка

**Снимок перед применением**:
Снимок, который применение записывает в хранилище применяющего до замены файлов. Становится текущим снимком. Публикацией не становится.
_Avoid_: бэкап, публикация

**Публикация**:
Снимок хранилища, который загрузка сделала видимым на странице аккаунта. У публикации постоянный адрес. Новая загрузка того же ИИ-агента прежние публикации не удаляет. Снятие прячет публикацию, снимок в хранилище остаётся.
_Avoid_: черновик, синхронизация, шаринг, пресет

**Навык**:
Папка с файлом SKILL.md внутри переносимой настройки.
_Avoid_: скилл

**Проект**:
Каталог, в котором запущена команда установки навыка.
_Avoid_: локальный проект, локальный агент

**Глобальный каталог**:
Каталог навыков ИИ-агента вне проекта. Навык оттуда виден во всех проектах этого ИИ-агента. Его место называет каталог ИИ-агентов.
_Avoid_: домашняя папка ИИ-агента, проект

**Установка навыка**:
Копирование выбранных навыков одной публикации в одного или нескольких ИИ-агентов из каталога. На одну команду приходится один выбор: глобальный каталог или проект. Пока человек не переключил, это глобальный каталог. Если у ИИ-агента нет выбранного места, он не предлагается. Папка навыка ложится прямо в каталог навыков ИИ-агента. Две выбранные папки с одним именем команду останавливают, и файлы не пишутся. ИИ-агенты с одним каталогом получают файлы один раз. Канон установка не меняет. Хранилище установка не пополняет и публикацией не становится. Вход в аккаунт не нужен. Версия, которую гость на странице не видит, в установку без входа не входит. Владелец открывает такую версию входом или подтверждением машины. Правило входа для своей публикации на установку не действует. Обрыв возвращает каталоги навыков всех ИИ-агентов этой команды к состоянию до попытки.
_Avoid_: применение, загрузка

**Подключение**:
Команда `agentsync <ИИ-агент> on`. Названный ИИ-агент начинает видеть элементы канона в своей домашней папке через ссылки. Ссылка не копия: правка в каноне сразу видна всем подключённым ИИ-агентам. Если имя элемента занято собственной папкой или файлом ИИ-агента, подключение сначала создаёт снимок ИИ-агента в его хранилище, затем ставит на это имя ссылку. Собственные элементы ИИ-агента с другими именами остаются у него и в канон не переходят. MCP-серверы канона ссылкой не подключить: подключение вписывает их в файл настроек ИИ-агента в его формате, и машина помнит, какие записи вписала она. Повторное подключение убирает свою запись, которой в каноне больше нет. Переменную секрета подключение пишет так, как её понимает ИИ-агент. Если ИИ-агент переменные не раскрывает, подключение подставляет значение с машины. Вид элементов, который ИИ-агент не понимает, подключение пропускает и называет в выводе, отказа нет. Чужие записи с другими именами и остальное содержимое файла остаются. Аккаунт и сервер не нужны. Применение публикации ИИ-агента подключает этого ИИ-агента. Обрыв возвращает домашнюю папку ИИ-агента к состоянию до попытки.
_Avoid_: разводка, синхронизация, подписка, проект

**Отключение**:
Команда `agentsync <ИИ-агент> off`. ИИ-агент перестаёт видеть элементы канона: ссылки на канон из его домашней папки уходят, в том числе ссылки на элемент, которого в каноне уже нет. Из файла настроек уходят только записи MCP, которые вписало подключение. Канон остаётся. Если ни ссылок, ни таких записей нет, команда ничего не меняет. Папка, которую положила установка навыка, остаётся.
_Avoid_: разводка, снятие, откат, удаление навыка

## Действия

**Подтверждённая почта**:
Почта аккаунта, которую человек подтвердил по письму. Ни одно действие сервиса её не требует. Письмо остаётся и может пригодиться позже, например для второго фактора.
_Avoid_: вход, имя

**Создание снимка**:
Явное действие над одним ИИ-агентом или каноном. Добавляет в его хранилище снимок переносимой настройки и делает его текущим. Правка файла сама снимок не создаёт. Пустую переносимую настройку и секрет в названном файле создание снимка не принимает.
_Avoid_: запись, загрузка, синхронизация, автосохранение

**Загрузка**:
Явное действие над одним снимком своего хранилища. Нужен вход в аккаунт. Делает этот снимок публикацией. Правка файла и создание снимка сами загрузку не вызывают.
_Avoid_: применение, запись, синхронизация

**Пояснение**:
Текст человеку, когда действие не выполнено. Называет причину. Значение секрета в текст не входит.
_Avoid_: ошибка

**Отказ создания снимка**:
Создание снимка, которое не добавило снимок. Пояснение называет причину: нет переносимой настройки, секрет в названном файле или аккаунт браузера не совпал с аккаунтом машины.
_Avoid_: ошибка, отказ записи

**Отказ загрузки**:
Загрузка, которая не стала публикацией. Пояснение называет причину: аккаунт браузера не совпал с аккаунтом машины или этого снимка в хранилище нет.
_Avoid_: ошибка

**Отказ подключения**:
Подключение, которое не изменило домашнюю папку ИИ-агента. Пояснение называет одну причину, по порядку: в каноне нечего показать, ИИ-агента нет в каталоге ИИ-агентов, в каноне два навыка с одним именем папки, секрет в названном файле. Эти причины проверяются до изменения файлов. Значение секрета в текст не входит. Аккаунт для отказа не нужен.
_Avoid_: ошибка, отказ разводки

**Применение**:
Разовое действие, которое переносит публикацию на машину применяющего. Перед изменением канон или переносимая настройка записывается в хранилище применяющего снимком перед применением, если в ней есть что записать. Публикация канона точно заменяет канон: элемент, которого в публикации нет, уходит из канона и остаётся в снимке. Публикация ИИ-агента заменяет в каноне только одноимённые элементы и добавляет новые, остальные элементы канона остаются. Собственные файлы ИИ-агента из публикации, которые не элементы канона, ложатся в его домашнюю папку по тому же правилу: одноимённый файл заменяется целиком, остальные остаются. Записи MCP и плагинов, которые вписало подключение, идут в канон, а не в файл настроек ИИ-агента. Затем этот ИИ-агент подключается. Машинный MCP, машинный хук, учётные данные и файлы программы остаются. Если применение обрывается, файлы возвращаются к состоянию до попытки, снимок попытки в хранилище не попадает, человек видит пояснение. Страница применяющего не меняется. Поздние публикации автора сами на машину не приходят.
_Avoid_: слияние, синхронизация, деплой, подписка

**Применение снимка**:
Разовая точная замена переносимой настройки выбранным снимком своего хранилища. Если настройка отличается от текущего снимка, она сначала записывается в хранилище. Затем выбранный снимок становится текущим. Само на другую машину не приходит.
_Avoid_: применение, синхронизация

**Кнопка применения**:
Команда на странице публикации. Её выполняет локальный агент компьютера, где открыта страница. Без входа она применяет только чужую публикацию. Свою публикацию применяют после входа. Если локальный агент не отвечает, остаётся инструкция применения.
_Avoid_: инструкция применения

**Откат**:
Возврат одного ИИ-агента или канона на этой машине по хранилищу. Если переносимая настройка разошлась с текущим снимком, откат возвращает файлы к текущему снимку и текущим оставляет его. Если настройка уже совпадает с текущим снимком, текущим становится предыдущий снимок, и его файлы ложатся на машину. Ушедший снимок в хранилище остаётся. Делается со страницы аккаунта после входа, когда локальный агент компьютера принадлежит этому аккаунту. Публикации не меняет.
_Avoid_: снятие, применение

**Снятие**:
Действие автора над одной публикацией после входа. Локальный агент для него не нужен. После снятия публикацию нельзя открыть и нельзя применить заново. Машины, где она уже применена, остаются как есть. Кнопка карточки переходит на предыдущую оставшуюся публикацию. Если её нет, кнопки применения у карточки нет.
_Avoid_: снятие подтверждения машины, удаление аккаунта, откат

**Предпросмотр**:
Содержимое публикации до применения. Совпадает с тем, что применение изменит. Доступен без входа в сервис. Машинных хуков и машинного MCP там нет.
_Avoid_: дифф

**Инструкция установки**:
Одна страница сайта, по которой ИИ-агент ставит локальный агент и доводит его до подтверждения машины. Публикацию не применяет и ИИ-агента не загружает.
_Avoid_: инструкция применения

**Инструкция применения**:
Страница одной публикации. Чужую публикацию ИИ-агент применяет через локальный агент без входа в браузер. Свою публикацию инструкция применяет только когда в браузере открыт этот аккаунт, иначе останавливается с пояснением. Если локального агента нет, выполнение переходит к инструкции установки и ИИ-агента не изменяет.
_Avoid_: инструкция установки, инструкция загрузки

**Удаление аккаунта**:
Действие владельца, которое проходит только после повторного верного пароля. Публикации снимаются, хранилище в облаке удаляется, имя освобождается, страница уходит из списка, лайки этого аккаунта снимаются с чужих страниц. Копии хранилища на дисках и уже применённые чужие машины остаются как были. Новому аккаунту эти копии не показываются.
_Avoid_: снятие, снятие подтверждения машины

**Инструкция загрузки**:
Страница сайта, где каждый ИИ-агент назван отдельно. По ней ИИ-агент через локальный агент создаёт снимок названного и загружает его. Если локального агента нет, выполнение переходит к инструкции установки.
_Avoid_: инструкция применения, инструкция установки
