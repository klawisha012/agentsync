# AgentSync

Сервис, в котором снимок ИИ-агента лежит в частном хранилище, загрузка делает снимок публикацией, а другой аккаунт разово применяет её у себя.

## Участники

**Аккаунт**:
Человек в сервисе. Ему принадлежат его публикации, и локальный агент входит именно в аккаунт.
_Avoid_: пользователь, авторизация

**Имя**:
Публичное имя страницы, уникальное без учёта регистра: 3–32 знака из букв любого алфавита, цифр и дефиса не по краям. Имена страниц самого сайта заняты. Похожие буквы разных алфавитов остаются разными именами. После подтверждения почты имя можно сменить, адреса публикаций от этого не меняются, почта на странице не показывается.
_Avoid_: логин, ник, email

**Страница аккаунта**:
Место, где видны публикации аккаунта. Карточка ИИ-агента есть только у того, чья публикация открыта. У карточки одна кнопка применения последней публикации. Прежние публикации можно открыть отдельно. Предпросмотр открывается без входа в сервис.
_Avoid_: профиль, лента, черновик

**Список аккаунтов**:
Общий перечень всех аккаунтов. В нём есть поиск, число просмотров страницы и число лайков страницы. Набор имён ИИ-агентов там не объявлен. По умолчанию выше лайки. При равенстве выше просмотры, затем имя. Список можно пересортировать по просмотрам, по имени и по времени последней публикации. Аккаунт без публикации в сортировке по времени идёт последним.
_Avoid_: каталог, лента, профиль

**Поиск**:
Строка списка аккаунтов. Ищет имя как текст: без учёта регистра, по вхождению набранных символов. Текст файлов публикаций не ищет. С первого символа под строкой открыт выпадающий список аккаунтов, и он обновляется на каждый новый символ. Пустая строка показывает весь список без выпадающего списка.
_Avoid_: точный поиск, поиск по файлам, поиск по кнопке

**Просмотр**:
Один человек даёт чужой странице один просмотр за всё время. Браузер без входа считает его один раз. Вход с этого браузера привязывает просмотр к аккаунту и второй не добавляет, в том числе с другого компьютера. Владелец, повторное открытие и предпросмотр публикации счётчик не увеличивают.
_Avoid_: предпросмотр, просмотр публикации, лайк

**Лайк**:
Отметка чужой страницы аккаунта вошедшим аккаунтом. На страницу приходится один лайк аккаунта. Повторное нажатие снимает лайк. Свою страницу отметить нельзя. Подтверждённая почта не нужна.
_Avoid_: избранное, плюс, лайк публикации

**Локальный агент**:
Программа на машине аккаунта, которая записывает снимки в хранилище, загружает их как публикации и применяет публикации.
_Avoid_: демон, клиент, CLI, ИИ-агент

**Подтверждение машины**:
Действие человека на сайте после входа, после которого локальный агент входит в его аккаунт. У компьютера один аккаунт за раз: новое подтверждение сменяет прежнее. Копия хранилища прежнего аккаунта остаётся на диске и новому не показывается.
_Avoid_: пароль, код, токен

**Снятие машины**:
Действие владельца после входа. Локальный агент перестаёт входить в аккаунт. Хранилище аккаунта остаётся. Подтверждённая почта для этого не нужна.
_Avoid_: удаление аккаунта, откат

## Содержимое

**ИИ-агент**:
Любой именованный агент, чью переносимую настройку публикуют и применяют отдельно от остальных. Зарезервированного набора имён нет: имя видно там, где есть его открытая публикация.
_Avoid_: дом, ИИ-дом, папка, бандл, агент

**Домашняя папка ИИ-агента**:
Каталог на машине, в котором лежат файлы одного ИИ-агента. Переносимая настройка — только часть этой папки.
_Avoid_: дом, ИИ-дом

**Переносимая настройка**:
Часть домашней папки ИИ-агента, которая задаёт его поведение: конфиг, хуки без абсолютного пути, тема, включённые плагины, правила, навыки, плагины и MCP, кроме машинного MCP и машинного хука.
_Avoid_: домашняя папка ИИ-агента, конфиг

**Машинный MCP**:
MCP, привязанный к конкретной машине или к секрету: абсолютный путь, секретный заголовок, токен в окружении. В публикацию не входит. При применении такой MCP на машине остаётся.
_Avoid_: MCP

**Машинный хук**:
Хук, в команде которого есть абсолютный путь. В публикацию не входит ни хук, ни скрипт, на который он ссылается. При применении машинные хуки этой машины остаются.
_Avoid_: хук, машинный MCP

**Коннектор**:
Частная интеграция под одну задачу, отдельно от MCP и от плагина. В разводку не входит.
_Avoid_: MCP, плагин

**Поставка**:
Файлы, которые приходят вместе с установкой продукта, и их кэши. В публикацию не входят и при применении не меняются.
_Avoid_: настройка, ИИ-агент

**Учётные данные**:
Вход владельца в сам ИИ-агент на этой машине. В публикацию не входят и при применении не перезаписываются.
_Avoid_: авторизация, токен, сессия, секрет

**Секрет**:
Значение внутри переносимого файла, которое даёт доступ к чужому ресурсу. Пока секрет лежит в файле, запись в хранилище не проходит и публикация из этого снимка не создаётся.
_Avoid_: учётные данные

**Снимок**:
Копия переносимой настройки одного ИИ-агента на момент записи. В хранилище снимок неизменяем.
_Avoid_: бэкап, бандл, архив, коммит

**Хранилище**:
Частная история снимков одного ИИ-агента одного аккаунта. Другой аккаунт его не открывает и не применяет. На странице аккаунта его видит только вошедший владелец. Снимки остаются. На другую машину того же аккаунта само не приходит. Файлы там меняет только явное применение выбранного снимка.
_Avoid_: цепочка, репозиторий, git, синхронизация, черновик, облачный бэкап

**Текущая метка**:
Метка хранилища на один его снимок. Запись ставит её на новый снимок.
_Avoid_: голова, ветка

**Снимок перед применением**:
Снимок, который применение чужой публикации записывает в хранилище применяющего до замены файлов. Текущая метка переходит на него. Публикацией не становится.
_Avoid_: бэкап, публикация

**Цепочка**:
Прежнее имя истории снимков одной машины. Теперь это хранилище.
_Avoid_: облачный бэкап

**Публикация**:
Снимок хранилища, который загрузка сделала видимым на странице аккаунта. У публикации постоянный адрес. Новая загрузка того же ИИ-агента прежние публикации не удаляет. Снятие прячет публикацию, снимок в хранилище остаётся.
_Avoid_: черновик, синхронизация, шаринг, пресет

**Навык**:
Папка с файлом SKILL.md внутри переносимой настройки.
_Avoid_: скилл

**Приёмник**:
Программа, которая не ИИ-агент и на странице аккаунта не появляется. В неё кладут выбранные навыки, и она может участвовать в разводке. Каталог приёмников поставляется вместе с сервисом. Если для выбранного места каталога нет, приёмник не предлагается.
_Avoid_: ИИ-агент, агент

**Проект**:
Каталог, в котором запущена команда установки навыка.
_Avoid_: локальный проект, локальный агент

**Глобальный каталог**:
Каталог навыков приёмника вне проекта. Навык оттуда виден во всех проектах этого приёмника. Его место считается так же, как в каталоге установки навыков.
_Avoid_: домашняя папка ИИ-агента, проект

**Установка навыка**:
Размещение выбранных навыков одной публикации в один или несколько приёмников. На одну команду приходится один выбор: глобальный каталог или проект. Пока человек не переключил, это глобальный каталог. Папка навыка ложится прямо в каталог навыков приёмника. Две выбранные папки с одним именем команду останавливают, и файлы не пишутся. Приёмники с одним каталогом получают файлы один раз. Хранилище установка не пополняет и публикацией не становится. Обрыв возвращает каталоги навыков всех приёмников этой команды к состоянию до попытки.
_Avoid_: применение, загрузка

**Разводка**:
Видимость всех навыков, которые в момент действия лежат в домашней папке одного ИИ-агента, в глобальном каталоге названных приёмников на той же машине. Навык разводки — самая внешняя папка с SKILL.md в переносимой настройке. Внутренний SKILL.md остаётся частью той же записи. Имя у приёмника — имя этой папки. У каждого такого навыка своя общая запись с каноном, каталог целиком общей записью не становится. Если глобального каталога на диске нет, разводка его создаёт. Повторное включение приводит набор к текущему канону: новый навык становится виден, навыка, которого в каноне больше нет, приёмник не видит. Установка может положить рядом свою папку. Другой ИИ-агент может показать этому приёмнику навык с другим именем. Человек называет приёмников при включении и при выключении, машина набор не хранит. Аккаунт, подтверждение машины и сервер не нужны. Имя, которое уже общая запись с этим каноном, занятым не считается. Ноль навыков, два навыка с одним именем папки, секрет в файле навыка и имя, занятое чужой папкой, — отказ, приёмники не меняются. Обрыв возвращает каталоги всех приёмников этого действия к состоянию до попытки. Применением не включается, и приёмник своей публикацией не становится. MCP, хуки, плагины, правила, тема, конфиг и коннектор в разводку не входят.
_Avoid_: синхронизация, подписка, проект

**Выключение разводки**:
Явное действие над одним ИИ-агентом и названными приёмниками. Набор приёмников машина не хранит. Приёмник перестаёт видеть навык, чья запись принадлежит домашней папке этого ИИ-агента, в том числе если самой папки навыка уже нет. Если такой записи нет, действие ничего не меняет. Домашняя папка остаётся. Папка навыка, которую положила установка и которая не общая запись с каноном, остаётся у приёмника.
_Avoid_: снятие, откат, удаление навыка

## Действия

**Подтверждённая почта**:
Почта аккаунта, которую человек подтвердил по письму. Подтверждение не закрывает запись, загрузку, снятие, смену имени, откат и применение. Письмо остаётся и может пригодиться позже, например для второго фактора.
_Avoid_: вход, имя

**Запись**:
Явное действие над одним ИИ-агентом. Добавляет в его хранилище снимок переносимой настройки и ставит на него текущую метку. Подтверждённая почта не нужна. Правка файла сама запись не вызывает. Пустую переносимую настройку и секрет в названном файле запись не принимает.
_Avoid_: загрузка, синхронизация, автосохранение

**Загрузка**:
Явное действие над одним снимком своего хранилища. Нужен вход в аккаунт. Делает этот снимок публикацией. Подтверждение почты не нужно. Правка файла и запись сами загрузку не вызывают.
_Avoid_: применение, запись, синхронизация

**Пояснение**:
Текст человеку, когда действие не выполнено. Называет причину. Значение секрета в текст не входит.
_Avoid_: ошибка

**Отказ записи**:
Запись, которая не добавила снимок. Пояснение называет причину: нет переносимой настройки, секрет в названном файле или аккаунт браузера не совпал с аккаунтом машины.
_Avoid_: ошибка

**Отказ загрузки**:
Загрузка, которая не стала публикацией. Пояснение называет причину: почта не подтверждена, аккаунт браузера не совпал с аккаунтом машины или этого снимка в хранилище нет.
_Avoid_: ошибка

**Отказ разводки**:
Разводка, которая не изменила приёмников. Пояснение называет одну причину, по порядку: нет навыков, нет названного приёмника, в каноне два навыка с одним именем папки, секрет в названном файле навыка, имя навыка уже занято не этой записью. Эти причины проверяются до изменения каталогов. Значение секрета в текст не входит. Аккаунт для отказа не нужен.
_Avoid_: ошибка

**Применение**:
Разовая точная замена переносимой настройки одного ИИ-агента публикацией. Перед заменой переносимая настройка записывается в хранилище применяющего, если в ней есть что записать. Файл, которого в публикации нет, уходит из ИИ-агента и остаётся в этом снимке. Машинный MCP, машинный хук, учётные данные и поставка остаются. Если применение обрывается, переносимая настройка возвращается к состоянию до попытки, снимок попытки в хранилище не попадает, человек видит пояснение. Страница применяющего не меняется. Поздние публикации автора сами на машину не приходят.
_Avoid_: слияние, синхронизация, деплой, подписка

**Применение снимка**:
Разовая точная замена переносимой настройки выбранным снимком своего хранилища. Если настройка отличается от текущей метки, она сначала записывается в хранилище. Затем метка переходит на выбранный снимок. Само на другую машину не приходит.
_Avoid_: применение, синхронизация

**Кнопка применения**:
Команда на странице публикации. Её выполняет локальный агент компьютера, где открыта страница. Без входа она применяет только чужую публикацию. Свою публикацию применяют после входа. Если локальный агент не отвечает, остаётся инструкция применения.
_Avoid_: инструкция применения

**Откат**:
Возврат одного ИИ-агента на этой машине по хранилищу. Если переносимая настройка разошлась с текущей меткой, откат записывает метку в ИИ-агента и метку не переносит. Если настройка уже совпадает с меткой, метка переходит на предыдущий снимок, и этот снимок записывается в ИИ-агента. Ушедший снимок в хранилище остаётся. Делается со страницы аккаунта после входа, когда локальный агент компьютера принадлежит этому аккаунту. Публикации не меняет. Подтверждённая почта не нужна.
_Avoid_: снятие, применение

**Снятие**:
Действие автора над одной публикацией после входа и подтверждения почты. Локальный агент для него не нужен. После снятия публикацию нельзя открыть и нельзя применить заново. Машины, где она уже применена, остаются как есть. Кнопка ИИ-агента переходит на предыдущую оставшуюся публикацию этого ИИ-агента. Если её нет, кнопки применения у этого ИИ-агента нет.
_Avoid_: удаление аккаунта, откат

**Предпросмотр**:
Содержимое публикации до применения. Совпадает с тем, что применение изменит в переносимой настройке. Доступен без входа в сервис. Машинных хуков и машинного MCP там нет.
_Avoid_: дифф

**Инструкция установки**:
Одна страница сайта, по которой ИИ-агент ставит локальный агент и доводит его до подтверждения машины. Публикацию не применяет и ИИ-агента не загружает.
_Avoid_: инструкция применения

**Инструкция применения**:
Страница одной публикации. Чужую публикацию ИИ-агент применяет через локальный агент без входа в браузер. Свою публикацию инструкция применяет только когда в браузере открыт этот аккаунт, иначе останавливается с пояснением. Если локального агента нет, выполнение переходит к инструкции установки и ИИ-агента не изменяет.
_Avoid_: инструкция установки, инструкция загрузки

**Удаление аккаунта**:
Действие владельца, которое проходит только после повторного верного пароля. Публикации снимаются, хранилище в облаке удаляется, имя освобождается, страница уходит из списка, лайки этого аккаунта снимаются с чужих страниц. Подтверждённая почта не нужна. Копии хранилища на дисках и уже применённые чужие машины остаются как были. Новому аккаунту эти копии не показываются.
_Avoid_: снятие, снятие машины

**Инструкция загрузки**:
Страница сайта, где каждый ИИ-агент назван отдельно. По ней ИИ-агент через локальный агент записывает названного в хранилище и загружает новый снимок. Если локального агента нет, выполнение переходит к инструкции установки.
_Avoid_: инструкция применения, инструкция установки
