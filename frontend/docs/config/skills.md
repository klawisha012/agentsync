# Навыки

Команда `skills` копирует выбранные навыки из одной версии публикации в каталоги навыков выбранных ИИ-агентов. Остальная настройка не меняется.

```sh
agentsync skills Author claude --version 4 --global --into cursor ru-text
```

| Часть | Значение |
|---|---|
| `Author claude` | автор и карточка публикации |
| `--version 4` | номер опубликованной версии |
| `--global` | глобальный каталог навыков ИИ-агента; `--project` — каталог навыков текущего проекта |
| `--into cursor` | ИИ-агент из [каталога](../reference/catalog.md); флаг повторяется для каждого ИИ-агента |
| `ru-text` | навык; навыков может быть несколько, каждый отдельным аргументом |

Навык — папка с `SKILL.md`. Имя можно дать коротко (`ru-text`) или путём (`skills/ru-text`). Флаг `--skill` тоже принимает один навык и может повторяться.

## Интерактивный выбор

```sh
agentsync skills Author claude --version 4 ru-text
```

Без `--into` и без `--global` или `--project` команда сначала спрашивает ИИ-агентов, затем место: текущий проект или глобально. Управление — стрелки, поиск, пробел и Enter. Если у ИИ-агента нет выбранного места, он не предлагается.

## Как ложатся файлы

- Папка навыка ложится прямо в каталог навыков ИИ-агента. Остальные навыки не меняются.
- ИИ-агенты с одним каталогом получают файлы один раз.
- Две выбранные папки с одним именем команду останавливают, и файлы не пишутся.
- Если установка обрывается, каталоги навыков всех ИИ-агентов команды возвращаются к состоянию до попытки.
- `~/.agents` установка не меняет, хранилище не пополняет, публикацию не создаёт. `agentsync <ии-агент> off` установленную папку не удаляет.

## Доступ

- Вход в аккаунт не нужен.
- Открытую версию команда копирует без сессии и без токена.
- Скрытую версию копирует только владелец: с сессией своего аккаунта (`AGENTSYNC_COOKIE` или `agentsync login`) или с токеном своей машины (`AGENTSYNC_TOKEN`).

## Навыки со страницы версии

На странице версии публикации включите «Выделение», отметьте навыки — сайт соберёт готовую команду `agentsync skills` для выбранных навыков.

## Навыки для всех ИИ-агентов сразу

Если навык нужен всем ИИ-агентам машины, положите его в `~/.agents/skills` и подключите ИИ-агентов: [agents и подключение](./agents.md).
