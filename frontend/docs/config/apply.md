# Применение

Применение — разовое действие, которое переносит публикацию `agents` автора на вашу машину в `~/.agents`. Поздние публикации автора сами на машину не приходят: для них нужно новое применение.

```sh
agentsync apply Author
```

`Author` — имя автора на сайте. Команду применения можно скопировать на странице аккаунта или публикации.

## Публикация agents

Публикация `agents` точно заменяет переносимые элементы `~/.agents`: элемент, которого в публикации нет, уходит из `~/.agents` и остаётся в локальном снимке. Файл `~/.agents/.env` и машинные MCP-серверы остаются. После применения все подключённые ИИ-агенты подключаются заново и видят обновлённый `~/.agents`.

Если `hooks.json` публикации в старом формате (без `"version": 1`), применение отказывает и `~/.agents` не меняется: `Хуки в ~/.agents/hooks.json в старом формате…`.

::: danger Это заменяет общую настройку всех подключённых ИИ-агентов
Применение чужой публикации `agents` меняет то, что видят все подключённые ИИ-агенты машины. Вернуть прежний `~/.agents` можно командой `agentsync revert agents`.
:::

## Что сохраняется

Применение не трогает:

- учётные данные ИИ-агентов (вход в сами ИИ-агенты);
- машинные MCP-серверы и машинные хуки этой машины;
- собственные файлы программ ИИ-агентов и их кэши;
- `~/.agents/.env`.

## Снимок перед применением

Перед изменением текущий `~/.agents` записывается в локальный снимок на этой машине. Откат:

```sh
agentsync revert agents
```

## Обрыв

Если применение обрывается, файлы `~/.agents` возвращаются к состоянию до попытки, лишний снимок не остаётся, а CLI печатает пояснение.

## Своя публикация

Свою публикацию применяют только с открытой сессией этого аккаунта (`agentsync login`). Чужую открытую публикацию применяют без входа. Скрытую чужую публикацию применить нельзя: команда печатает пояснение.

## Команда со страницы сайта

Страница аккаунта и страница публикации показывают команду применения. Кнопка «Скопировать» кладёт её в буфер обмена, затем выполните её в терминале. Если автор закрыл копирование команды в [настройках приватности](../site/privacy.md), команды применения на странице нет.
