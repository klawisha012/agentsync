# Локальные снимки

Снимок — копия переносимой настройки одного ИИ-агента или `~/.agents` на момент создания. Снимок неизменяем. Снимки одного ИИ-агента одного аккаунта образуют его хранилище.

## Создать снимок

```sh
agentsync record claude
```

Команда добавляет снимок в хранилище на сервере, печатает ответ сервера и оставляет копию в `~/.agentsync/store`. Публикацию эта команда не создаёт.

- Нужен вход в аккаунт.
- Правка файла сама снимок не создаёт: только явная команда.
- Пустую переносимую настройку и [секрет](../reference/security.md#секреты) в файле создание снимка не принимает и печатает пояснение.

## Посмотреть снимки

```sh
agentsync store claude
agentsync store claude 2
```

Без номера команда печатает список снимков. С номером печатает один снимок и сохраняет его копию локально.

Хранилище частное: его видит только владелец после входа. Другой аккаунт его не открывает и не применяет.

## Откатить

```sh
agentsync revert claude
agentsync revert agents
```

Команда берёт последний снимок этого аккаунта и этого ИИ-агента на машине и возвращает его файлы. После отката этот снимок из локальной цепочки уходит. Публикации на сервере не меняются.

- Сервер и вход не нужны.
- Учётные данные, машинные MCP-серверы и машинные хуки остаются на месте.
- После отката `agents` подключённые ИИ-агенты подключаются заново и видят прежний `~/.agents`.

::: warning Откат меняет текущие файлы
Сначала сохраните важные изменения: `agentsync record <ии-агент>`.
:::

## Снимки, которые создаются сами

| Когда | Что записывается |
|---|---|
| Перед [применением](./apply.md) | `~/.agents` и переносимая настройка ИИ-агента — снимками перед применением |
| Перед `on` поверх занятого имени | переносимая настройка ИИ-агента вместе с занятой папкой |

Если применение обрывается, снимок попытки в хранилище не попадает.

## Команда отката на сайте

Страница публикации показывает команду отката для этой машины, например `agentsync revert claude`. Скопируйте её и выполните в терминале.
