# Снимки и откат

Снимок — неизменяемая копия переносимой настройки на момент создания. Серверное хранилище хранит снимки `~/.agents` (`agents`), а локальные цепочки отката хранят снимки `~/.agents` и подключённых ИИ-агентов на этой машине.

## Создать снимок `~/.agents`

```sh
agentsync record
```

Команда добавляет снимок `~/.agents` в частное хранилище на сервере, печатает ответ сервера и оставляет копию в `~/.agentsync/store`. Публикацию эта команда не создаёт.

- Нужен вход в аккаунт.
- Правка файла сама снимок не создаёт: только явная команда.
- Пустую переносимую настройку и [секрет](../reference/security.md#секреты) в файле создание снимка не принимает и печатает пояснение.

## Посмотреть снимки

```sh
agentsync store
agentsync store 2
```

Без номера команда печатает список снимков `~/.agents`. С номером печатает один снимок и сохраняет его копию локально.

Хранилище частное: его видит только владелец после входа. Другой аккаунт его не открывает и не применяет.

## Откатить

```sh
agentsync revert agents
agentsync revert claude
```

Команда берёт последний локальный снимок `~/.agents` или названного ИИ-агента на этой машине и возвращает его файлы. После отката этот снимок из локальной цепочки уходит. Публикации на сервере не меняются.

- Сервер и вход не нужны.
- Учётные данные, `.env`, машинные MCP-серверы и машинные хуки остаются на месте.
- После `agentsync revert agents` подключённые ИИ-агенты подключаются заново и видят прежний `~/.agents`.

::: warning Откат меняет текущие файлы
Перед откатом `agents` можно сохранить текущее состояние командой `agentsync record`.
:::

## Снимки, которые создаются сами

| Когда | Что записывается локально |
|---|---|
| Перед [применением](./apply.md) или `export` | текущий `~/.agents` |
| Перед `on` поверх занятого имени | переносимая настройка ИИ-агента вместе с занятой папкой |

Если операция обрывается, файлы возвращаются к состоянию до попытки, а лишний снимок не сохраняется.
