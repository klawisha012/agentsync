# Публикация

Публикация — снимок переносимой настройки, который видят другие. Её создаёт загрузка: явное действие над одним ИИ-агентом.

## Один ИИ-агент

```sh
agentsync push claude
```

Команда читает домашнюю папку ИИ-агента, оставляет переносимые файлы и отправляет их на сервер. На странице аккаунта появляется или обновляется карточка этого ИИ-агента.

- Нужен вход в аккаунт. Подтверждение почты не нужно.
- Пароль в команду не входит.
- Имя ИИ-агента — имя его папки без точки (`.claude` → `claude`) или имя из [каталога ИИ-агентов](../reference/catalog.md) и его синоним (`claude-code`).

### Перенос в agents

`push` и `record` ИИ-агента из каталога сначала переносят его собственные хуки и MCP-серверы в `~/.agents` в формате agents. Отдельной команды нет.

```text
В agents перенесены: хуки (2), MCP-серверы: docs.
Не перенесены в agents: MCP-сервер github (имя занято в agents).
```

1. Сначала проверяется секрет. Если в собственном файле есть значение секрета, команда отказывает, и ничего не меняется.
2. Затем создаётся снимок `~/.agents`: `agentsync revert agents` вернёт `~/.agents` к состоянию до переноса.
3. Записи ложатся в `~/.agents/hooks.json` и `~/.agents/mcp.json`. Хук получает `"input"` своего ИИ-агента, а `$CLAUDE_PROJECT_DIR` и подобные переменные становятся `${AGENTS_PROJECT_DIR}`. Хук, который словарь agents не выражает (regex в `matcher`, событие одного ИИ-агента), ложится в раздел расширений этого ИИ-агента.
4. ИИ-агент подключается заново: прежние собственные записи становятся записями подключения. Удаление элемента из `~/.agents` убирает его и у ИИ-агента, а следующий `push` его не вернёт.
5. Затем создаётся снимок ИИ-агента, как раньше.

Если имя уже есть в `~/.agents`, запись `~/.agents` остаётся, а собственная запись остаётся у ИИ-агента. Машинные хуки, машинные MCP-серверы и навыки не переносятся. Если перенос обрывается, `~/.agents` и домашняя папка ИИ-агента возвращаются к состоянию до попытки.

::: warning Перенесённое видят все подключённые ИИ-агенты
После `push grok` хук Grok есть в `~/.agents` и после их следующего `on` доходит до Claude, Codex и Gemini. Вывод называет каждую перенесённую запись.
:::

## Общий каталог `~/.agents`

```sh
agentsync push agents
```

`~/.agents` публикуется отдельной карточкой с именем `agents`. Файл `~/.agents/.env` со значениями секретов в снимок не входит. Подробно: [agents и подключение](./agents.md).

## Все ИИ-агенты сразу

```sh
agentsync all
```

Команда ищет домашние папки ИИ-агентов в домашнем каталоге и публикует каждую отдельно, как `push`.

- Папка подходит, если в ней сразу лежат навыки, правила, конфиг, хуки, MCP или `AGENTS.md`.
- `~/.agents` тоже публикуется — под именем `agents`.
- Пустая папка и каталог `.agentsync` не публикуются.
- Если одна публикация не проходит, команда продолжает остальные.

## Что входит в публикацию

Переносимая настройка — часть домашней папки, которая задаёт поведение ИИ-агента:

| Входит | Примеры |
|---|---|
| Навыки | `skills/<навык>/SKILL.md` |
| Субагенты и пользовательские команды | `agents/*.md`, `commands/*.md`, `prompts/*.md` |
| Файл инструкций | `AGENTS.md`, `CLAUDE.md`, `GEMINI.md` |
| Настройки | `settings.json`, `config.json`, каталог `config/` |
| Правила и тема | `rules/`, `theme/` |
| MCP-серверы без машинных путей | `mcp.json`, `*.mcp.json`, каталог `mcp/` |
| Хуки без машинных путей | `hooks.json`, каталог `hooks/`, раздел `hooks` в `settings.json` |
| Записи плагинов | `plugins.json`, `enabledPlugins` в `settings.json` |

Ссылки на `~/.agents` в домашней папке ИИ-агента публикация разворачивает в копии. Поэтому карточка ИИ-агента показывает всё, что он видит, и один навык может быть в двух карточках.

Что никогда не уходит на сервер — учётные данные, `.env`, кэши, клоны маркетплейсов, машинные MCP и хуки: [Что не публикуется](../reference/security.md).

## Отказ загрузки

Если загрузка не прошла, CLI печатает пояснение с причиной. Значение секрета в пояснение не входит.

| Пояснение | Что сделать |
|---|---|
| `Секрет в файле <путь>.` | Замените значение [переменной секрета](../kinds/mcp.md#переменные-секрета) `${NAME}` и положите значение в окружение или `~/.agents/.env`. |
| `на компьютере нет этого ИИ-агента` | Проверьте имя: `agentsync push <имя папки без точки>`. |
| Аккаунт браузера не совпал с аккаунтом машины | Войдите заново: `agentsync login`. |

## Снятие публикации

Автор снимает публикацию на сайте, на странице аккаунта. Подробно: [Страница аккаунта](../site/account.md#снятие-публикации).
