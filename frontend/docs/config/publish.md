# Публикация

Публикация — неизменяемый снимок переносимой настройки `~/.agents`, который видят другие на странице аккаунта в карточке `agents`.

## Загрузить `~/.agents`

```sh
agentsync push
```

Команда читает общий каталог `~/.agents`, оставляет переносимые файлы, записывает снимок и публикует новую версию карточки `agents` на странице аккаунта.

- Нужен вход в аккаунт (`agentsync login`). Подтверждение почты для загрузки не требуется.
- Пароль в команду не входит.
- Файл `~/.agents/.env` со значениями секретов в снимок и публикацию не входит.

### Сбор настройки ИИ-агентов перед публикацией

Домашние папки отдельных ИИ-агентов напрямую на сервер не публикуются. Чтобы перенести навыки, субагентов, команды, инструкции, MCP-серверы, плагины и хуки из установленных ИИ-агентов в `~/.agents`, сначала выполните:

```sh
agentsync export
agentsync push
```

Подробно об устройстве `~/.agents` и подключении ИИ-агентов: [agents и подключение](./agents.md).

## Что входит в публикацию

Переносимая настройка `~/.agents`:

| Входит | Примеры |
|---|---|
| Навыки | `skills/<навык>/SKILL.md` |
| Субагенты и пользовательские команды | `agents/*.md`, `commands/*.md` |
| Файл инструкций | `AGENTS.md` |
| MCP-серверы без машинных путей | `mcp.json` |
| Хуки без машинных путей | `hooks.json` |
| Записи плагинов | `plugins.json` |

Что никогда не уходит на сервер — учётные данные, `.env`, кэши, клоны маркетплейсов, машинные MCP и хуки: [Что не публикуется](../reference/security.md).

## Отказ загрузки

Если загрузка не прошла, CLI печатает пояснение с причиной. Значение секрета в пояснение не входит.

| Пояснение | Что сделать |
|---|---|
| `Секрет в файле <путь>.` | Замените значение [переменной секрета](../kinds/mcp.md#переменные-секрета) `${NAME}` и положите значение в окружение или `~/.agents/.env`. |
| `На компьютере нет ~/.agents.` | Соберите настройку командой `agentsync export` или создайте `~/.agents`. |
| Аккаунт браузера не совпал с аккаунтом машины | Войдите заново: `agentsync login`. |

## Снятие публикации

Автор снимает публикацию на сайте, на странице аккаунта. Подробно: [Страница аккаунта](../site/account.md#снятие-публикации).
