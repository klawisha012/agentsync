# Настройки аккаунта

Настройки — `zwarder.ru/settings`, после входа. Разделы: «Аккаунт» и «Приватность».

## Аккаунт

| Настройка | Что нужно |
|---|---|
| Аватар | файл изображения; аватар можно удалить |
| Почта | новая почта и текущий пароль |
| Имя | новое имя |
| Пароль | текущий пароль, новый пароль и его повтор |

### Имя

Имя — публичное имя страницы, уникальное без учёта регистра: 3–32 знака из букв любого алфавита, цифр и дефиса не по краям. Имена страниц самого сайта заняты. Похожие буквы разных алфавитов остаются разными именами.

После смены имени адреса публикаций не меняются. Почта на странице не показывается.

### Почта

Подтверждать почту не обязательно: ни одно действие сервиса не требует подтверждённой почты.

## Приватность

Профиль, команда применения, осмотр версий и комментарии: [Приватность и комментарии](./privacy.md).

## Удаление аккаунта

Удаление проходит только после повторного ввода верного пароля.

- Публикации снимаются, хранилище в облаке удаляется.
- Имя освобождается, страница уходит из списка аккаунтов.
- Лайки этого аккаунта снимаются с чужих страниц.
- Файлы на машинах остаются: копии хранилища на дисках и уже применённые чужие машины не меняются. Новому аккаунту эти копии не показываются.
