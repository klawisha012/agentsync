# Страница аккаунта

Страница аккаунта — `zwarder.ru/<имя>`. Она показывает публикации аккаунта карточками: у `agents` и у каждого ИИ-агента с открытой публикацией своя карточка.

## Карточка

Карточка показывает:

- имя ИИ-агента или «agents» и путь (`~/.claude`, `~/.agents`);
- номер последней версии и число переносимых файлов;
- время обновления и лайки;
- команду: владельцу — `agentsync push <ии-агент>`, гостю — `agentsync apply <автор> <ии-агент>`.

Кнопка «Скопировать» кладёт команду в буфер обмена. Ссылка «Версии» открывает все версии карточки.

## Версии и предпросмотр

Страница версии показывает файлы публикации деревом и содержимое выбранного файла. Предпросмотр совпадает с тем, что изменит применение. Машинных хуков и машинного MCP в нём нет. Вход для предпросмотра не нужен.

Над деревом файлов указан состав версии: навыки, субагенты, команды, MCP-серверы, плагины, хуки.

Режим «Выделение» отмечает навыки и собирает команду [`agentsync skills`](../config/skills.md) для выбранных навыков.

## Снятие публикации

Автор снимает публикацию на своей странице после входа. Локальный агент для этого не нужен.

- Снятую публикацию нельзя открыть и нельзя применить заново.
- Машины, где она уже применена, остаются как есть.
- Карточка переходит на предыдущую оставшуюся публикацию. Если её нет, у карточки нет команды применения.

## Подтверждённые машины

Владелец видит на своей странице подтверждённые машины и снимает подтверждение кнопкой «Снять». Подробно: [Вход и машина](../start/login.md#подтверждение-машины).

## Просмотры и лайки

- **Просмотр.** Один человек даёт чужой странице один просмотр за всё время. Владелец, повторное открытие и предпросмотр публикации счётчик не увеличивают.
- **Лайк.** Вошедший аккаунт отмечает чужую страницу или публикацию. Повторное нажатие снимает лайк. Свою страницу и свою публикацию отметить нельзя.

## Список аккаунтов

`zwarder.ru/accounts` — общий список аккаунтов с поиском. Поиск ищет имя без учёта регистра по вхождению символов; текст файлов публикаций он не ищет.

По умолчанию выше аккаунты с большим числом лайков, при равенстве — с большим числом просмотров, затем по имени. Список можно пересортировать по просмотрам, по имени и по времени последней публикации.

## Комментарии

Под публикациями есть раздел комментариев. Кто их видит и кто может писать, владелец задаёт в [настройках приватности](./privacy.md#комментарии).
