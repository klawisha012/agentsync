# Приватность и комментарии

Настройки приватности — в разделе «Приватность» на странице [настроек](./settings.md). Имя страницы видно всем. Снятие публикации всегда остаётся только у владельца.

## Профиль

| Режим | Что видят другие |
|---|---|
| Открытый | копируют команду применения, открывают текущую версию и все версии, оставляют комментарии |
| Скрытый | эти действия видны только владельцу |
| Частичный | часть действий открыта, часть скрыта |

«Открытый» или «Скрытый» ставит все пункты одинаково. Каждый пункт можно настроить отдельно:

| Пункт | Что открывает |
|---|---|
| Команда применения | другие копируют `agentsync apply <ваше имя> <ии-агент>` |
| Осмотр текущей версии | другие открывают файлы последней версии |
| Все версии | другие открывают прежние версии |

Скрытую версию CLI копирует и применяет только владелец: с сессией своего аккаунта или с токеном своей машины.

## Комментарии

| Режим | Кто видит | Кто пишет |
|---|---|---|
| Оставлять комментарии могут все | все | любой вошедший |
| Оставлять комментарии могут только вошедшие | только вошедшие; без входа раздел скрыт | вошедшие |
| Комментарии скрыты | только владелец | только владелец |
