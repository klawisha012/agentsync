# Установка CLI

CLI `agentsync` — отдельная программа для терминала. Установщик кладёт её в `~/.agentsync` и добавляет этот каталог в `PATH`.

::: warning Прочитайте скрипт перед запуском
Установщик выполняет загруженный код на вашем компьютере. Исходные скрипты лежат в [репозитории](https://github.com/klawisha012/agentsync/tree/main/scripts).
:::

## Linux и macOS

```sh
curl -fsSL https://zwarder.ru/api/install.sh | sh
```

## Windows

В PowerShell:

```powershell
iwr https://zwarder.ru/api/install.ps1 -useb | iex
```

## Проверка

Откройте новый терминал, чтобы `PATH` обновился, и выполните:

```sh
agentsync help
agentsync version
```

`agentsync version` печатает номер сборки. Сборка без номера печатает `dev`.

## Обновление

```sh
agentsync update
```

Команда скачивает сборку с того же адреса, что и установка, и заменяет текущий файл. Сервер без описания версии тоже подходит: команда сравнивает содержимое файла.

```sh
agentsync update --check
```

С флагом `--check` команда только сообщает, есть ли другая сборка, и файл не меняет.

### Автоматическая проверка

Копия в `~/.agentsync` проверяет обновление сама, не чаще раза в сутки, перед другими командами. Если локальный номер новее опубликованного, автоматическая замена не выполняется.

Переменная `AGENTSYNC_AUTO_UPDATE=0` выключает автоматическую проверку. Команда `agentsync update` при этом работает.

## Другой сервер

По умолчанию CLI работает с `https://zwarder.ru/api`. Переменная `AGENTSYNC_SERVER` задаёт другой адрес API, например для своего сервера. Все переменные: [Переменные окружения](../reference/env.md).
