# Плагины

Плагин — пакет из маркетплейса, который ИИ-агент скачивает сам. В `~/.agents` лежит только запись плагина: маркетплейс, имя плагина и признак включения. Файлы плагина и клоны маркетплейсов в `~/.agents` и в снимок не входят.

## Формат

`~/.agents/plugins.json` в форме настроек Claude Code:

```json
{
  "enabledPlugins": {
    "commit-commands@anthropic": true,
    "lint@acme": true
  },
  "extraKnownMarketplaces": {
    "acme": {
      "source": { "source": "github", "repo": "acme/claude-plugins" }
    }
  }
}
```

- `enabledPlugins` — плагины в форме `<плагин>@<маркетплейс>` и признак включения.
- `extraKnownMarketplaces` — источники маркетплейсов, которых ИИ-агент ещё не знает.

## Подключение

| ИИ-агент | Куда вписываются записи |
|---|---|
| Claude Code | `~/.claude/settings.json`, ключи `enabledPlugins` и `extraKnownMarketplaces` |
| Остальные | вид «плагины» пропускается |

`on` вписывает записи по тем же правилам, что и [MCP-серверы](./mcp.md#свои-и-чужие-записи):

- чужие плагины и маркетплейсы с другими именами остаются;
- одноимённую чужую запись `on` заменяет, а `off` возвращает;
- повторный `on` убирает свою запись, которой в `~/.agents` больше нет;
- `off` удаляет только свои записи.

После `on` ИИ-агент сам скачивает включённые плагины из маркетплейсов.

## Ограничения

- Навыки и хуки внутри плагина элементами `~/.agents` не становятся. ИИ-агент без плагинов не видит навыков из плагина.
- Плагин не распаковывается в навыки и хуки: обновление плагина приходит из его маркетплейса.
