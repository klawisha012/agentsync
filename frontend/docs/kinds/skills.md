# Навыки

Навык — папка с файлом `SKILL.md`. В `~/.agents` навыки лежат в `skills/`.

```text
~/.agents/skills/
  grill-me/
    SKILL.md
    references/rules.md
  writing/
    ru-text/
      SKILL.md
```

## Какие папки становятся навыками

- Навык — внешняя папка с `SKILL.md`. `SKILL.md` во вложенной папке навыка частью этого навыка и остаётся.
- Группирующая папка без `SKILL.md` (`writing/` выше) навыком не считается. Навык внутри неё (`ru-text`) показывается под своим именем.
- Две папки навыка с одним именем в разных группах — отказ подключения. Переименуйте одну из них.

## Как ИИ-агент видит навык

`agentsync <ии-агент> on` ставит в глобальный каталог навыков ИИ-агента ссылку на папку навыка: `~/.claude/skills/grill-me → ~/.agents/skills/grill-me`. Правка в `~/.agents` сразу видна ИИ-агенту.

Каталог навыков каждого ИИ-агента: [Каталог ИИ-агентов](../reference/catalog.md).

## Секреты в навыке

Если файл внутри навыка содержит значение секрета (токен, ключ API, пароль), подключение отказывает и называет файл. Значение секрета в пояснение не входит.

## Отдельные навыки из чужой публикации

Чтобы взять несколько навыков без применения всей публикации, используйте [`agentsync skills`](../config/skills.md).
