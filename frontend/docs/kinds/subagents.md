# Субагенты и пользовательские команды

## Субагенты

Субагент — описание отдельного ИИ-помощника с ролью и набором инструментов, в формате Claude Code: файл `*.md` с frontmatter.

```text
~/.agents/agents/
  go-developer.md
  reviewer.md
```

```markdown
---
name: go-developer
description: Пишет и правит код на Go по правилам проекта.
tools: Read, Edit, Bash
---

Ты — разработчик на Go…
```

`on` ставит ссылки на файлы `*.md` и папки из `~/.agents/agents`:

| ИИ-агент | Место |
|---|---|
| Claude Code | `~/.claude/agents/` |
| Остальные | пропускают вид «субагенты» |

## Пользовательские команды

Пользовательская команда — файл `*.md` с текстом запроса, который ИИ-агент запускает по имени `/имя`.

```text
~/.agents/commands/
  review.md        → /review
```

| ИИ-агент | Место |
|---|---|
| Claude Code | `~/.claude/commands/` |
| Остальные | пропускают вид «пользовательские команды» |

## Общие правила

- Ссылка ставится на каждый файл `*.md` и каждую папку верхнего уровня.
- Собственные файлы ИИ-агента с другими именами остаются у него.
- Одноимённый собственный файл уходит в снимок ИИ-агента, затем на его месте появляется ссылка.
- Повторный `on` убирает ссылку на файл, которого в `~/.agents` больше нет.
