# Файл инструкций

Файл инструкций — общие правила, которые ИИ-агент читает в начале каждой сессии. В `~/.agents` он один: `~/.agents/AGENTS.md`. Каждый ИИ-агент видит его под своим именем.

| ИИ-агент | Имя файла |
|---|---|
| Claude Code | `~/.claude/CLAUDE.md` |
| Codex | `~/.codex/AGENTS.md` |
| Gemini CLI | `~/.gemini/GEMINI.md` |
| Остальные | пропускают вид «файл инструкций» |

`on` ставит на это имя ссылку на `~/.agents/AGENTS.md`. Правка общего файла сразу видна всем подключённым ИИ-агентам.

## Свой файл уже есть

Если у ИИ-агента уже есть собственный `CLAUDE.md`, `on` сначала переносит его в снимок ИИ-агента, затем ставит ссылку. Вернуть прежний файл: `agentsync revert claude`.

Если `~/.agents/AGENTS.md` сам является ссылкой на файл ИИ-агента (например, на `~/.claude/CLAUDE.md`), `on` этот файл не трогает: ИИ-агент уже видит общие правила.

## Применение

Применение публикации ИИ-агента заменяет `~/.agents/AGENTS.md` целиком, как любой элемент `~/.agents`. Прежние правила остаются в снимке перед применением: `agentsync revert agents`.
