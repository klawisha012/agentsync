# Что такое AgentSync

AgentSync переносит настройку ИИ-агентов между машинами и людьми. ИИ-агент — программа для работы с ИИ: Claude Code, Codex, Gemini CLI, Cursor, Grok и другие. Его настройка — навыки, субагенты, пользовательские команды, файл инструкций, MCP-серверы, плагины и хуки.

AgentSync состоит из двух частей:

- **CLI `agentsync`** — локальный агент на вашей машине. Он создаёт снимки, загружает публикации, применяет чужие публикации, подключает ИИ-агентов к общему каталогу `~/.agents`.
- **Сайт [zwarder.ru](https://zwarder.ru/)** — страницы аккаунтов с публикациями. Публикацию можно посмотреть до применения, скопировать команду применения и взять из неё отдельные навыки.

## Как это устроено

```text
~/.agents            общая настройка всех ИИ-агентов машины (agents)
  skills/            навыки
  agents/            субагенты
  commands/          пользовательские команды
  AGENTS.md          файл инструкций
  mcp.json           MCP-серверы
  plugins.json       записи плагинов
  hooks.json         хуки
  .env               значения секретов (никуда не уходит)

~/.claude, ~/.codex, ~/.gemini, …   домашние папки ИИ-агентов
```

1. Общую настройку вы держите в одном месте — в `~/.agents`.
2. Команда `agentsync <ии-агент> on` показывает её ИИ-агенту. Навыки и файлы появляются у него ссылками, MCP-серверы, плагины и хуки вписываются в его файл настроек.
3. Команда `agentsync push <ии-агент>` публикует переносимую настройку. Учётные данные и машинные пути в публикацию не входят.
4. Другой человек применяет публикацию командой `agentsync apply <автор> <ии-агент>`. Перед изменением его прежняя настройка записывается в снимок, и откат возвращает её.
