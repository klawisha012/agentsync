# Глоссарий

Термины документации. Полный глоссарий проекта — [CONTEXT.md](https://github.com/klawisha012/agentsync/blob/main/CONTEXT.md).

**agents** — каталог `~/.agents` на машине: общая настройка, которую видят все подключённые ИИ-агенты. У него своя карточка, свой снимок и своё хранилище.

**Элемент agents** — наименьшая часть `~/.agents`, которую применение заменяет целиком: папка навыка, файл субагента, файл пользовательской команды, хук, запись MCP-сервера, запись плагина, файл инструкций.

**ИИ-агент** — программа для работы с ИИ, чью переносимую настройку публикуют и применяют: Claude Code, Codex, Gemini CLI, Cursor, Grok и другие.

**Каталог ИИ-агентов** — список ИИ-агентов, который поставляется с AgentSync. Называет имя, синонимы и места элементов. [Каталог](./catalog.md).

**Локальный агент** — программа `agentsync` на вашей машине.

**Подключение** — команда `agentsync <ии-агент> on`: ИИ-агент начинает видеть элементы `~/.agents`.

**Отключение** — команда `agentsync <ии-агент> off`: ссылки на `~/.agents` и записи, которые вписал `on`, уходят.

**Переносимая настройка** — часть домашней папки ИИ-агента, которая задаёт его поведение и может жить на другой машине.

**Снимок** — копия переносимой настройки одного ИИ-агента или `~/.agents` на момент создания. Неизменяем.

**Хранилище** — частная история снимков одного ИИ-агента или `~/.agents` одного аккаунта.

**Снимок перед применением** — снимок, который применение пишет само перед изменением файлов.

**Публикация** — снимок, который загрузка сделала видимым на странице аккаунта.

**Применение** — разовый перенос публикации на машину применяющего.

**Откат** — возврат ИИ-агента или `~/.agents` к последнему снимку на этой машине.

**Снятие** — действие автора: публикацию больше нельзя открыть и применить.

**Предпросмотр** — содержимое публикации до применения; совпадает с тем, что изменит применение.

**Навык** — папка с `SKILL.md`.

**Субагент** — описание отдельного ИИ-помощника в `agents/*.md`.

**Пользовательская команда** — запрос в `commands/*.md`, который ИИ-агент запускает по имени `/имя`.

**Файл инструкций** — `~/.agents/AGENTS.md`; ИИ-агенты видят его как `CLAUDE.md`, `AGENTS.md`, `GEMINI.md`.

**Плагин** — пакет из маркетплейса; в `~/.agents` хранится только его запись.

**Переменная секрета** — `${NAME}` вместо значения секрета; значение лежит в окружении или в `~/.agents/.env`.

**Секрет** — значение в файле, которое даёт доступ к чужому ресурсу. С ним снимок не создаётся.

**Машинный MCP** — MCP-сервер с абсолютным путём. В публикацию не входит.

**Машинный хук** — хук с абсолютным путём в команде. В публикацию не входит.

**Учётные данные** — вход владельца в сам ИИ-агент. В публикацию не входят и при применении не перезаписываются.

**Подтверждение машины** — действие на сайте, после которого локальный агент входит в ваш аккаунт.
