# Что не публикуется

Публикация несёт только переносимую настройку. Всё ниже остаётся на машине: при загрузке не отправляется, при применении и откате не перезаписывается.

## Учётные данные

Вход владельца в сам ИИ-агент на этой машине. Файлы и папки:

- `credentials.json`, `credentials`, `auth.json`, `session.json`;
- папки `credentials/`, `session/`, `sessions/`.

## Секреты

Секрет — значение в переносимом файле, которое даёт доступ к чужому ресурсу: ключ API, токен, пароль, заголовок `Authorization`, закрытый ключ. Пока секрет лежит в файле:

- снимок не создаётся, публикация из него не появляется;
- `on` отказывает, если секрет в элементе `~/.agents`, который он показывает ИИ-агенту.

Пояснение называет файл, но не значение. Вместо значения пишите [переменную секрета](../kinds/mcp.md#переменные-секрета) `${NAME}`.

## Файлы `.env`

`.env` и любые `.env.*` не входят в снимок. Значения секретов для `~/.agents` лежат в `~/.agents/.env`.

## Машинный MCP и машинный хук

- [MCP-сервер](../kinds/mcp.md#машинный-mcp) с абсолютным путём в `command`, `args` или `env`.
- [Хук](../kinds/hooks.md#машинный-хук) с абсолютным путём в команде, и скрипт, на который он ссылается.

Решается по серверу и по группе хука: соседние записи того же файла публикуются.

## Файлы программы и кэши

Файлы, которые приходят с установкой самого ИИ-агента, и временные данные:

- `node_modules/`, `vendor/`, `dist/`, `bundled/`;
- `cache/`, `caches/`, `marketplace-cache/`, клоны маркетплейсов плагинов;
- `logs/`, `log/`, `*.log`, `*.lock`, `locks/`;
- `memory/`, `history/`, `conversations/`.

## Каталог состояния AgentSync

`~/.agentsync` — сессия, токен машины, хранилище снимков, учёт записей `on`. Публикации не касается и в домашние папки ИИ-агентов не попадает.

## Предпросмотр

Предпросмотр публикации на сайте совпадает с тем, что применит применение. Если файла нет в предпросмотре, его нет и в публикации.
