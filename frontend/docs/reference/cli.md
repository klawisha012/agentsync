# Команды CLI

Справка в терминале: `agentsync help` — общий список, `agentsync help <команда>` — одна команда.

| Команда | Что делает | Вход |
|---|---|---|
| [`login`](#login) | входит в аккаунт | — |
| [`push`](#push) | публикует один ИИ-агент или `agents` | да |
| [`all`](#all) | публикует всех найденных ИИ-агентов | да |
| [`record`](#record) | записывает снимок в хранилище | да |
| [`store`](#store) | читает снимки из хранилища | да |
| [`revert`](#revert) | возвращает последний снимок на этой машине | нет |
| [`apply`](#apply) | применяет публикацию | для своей публикации |
| [`skills`](#skills) | ставит выбранные навыки публикации | нет |
| [`<ии-агент> on`](#on) | подключает ИИ-агента к `~/.agents` | нет |
| [`<ии-агент> off`](#off) | отключает ИИ-агента от `~/.agents` | нет |
| [`version`](#version) | печатает версию | нет |
| [`update`](#update) | обновляет CLI | нет |
| [`help`](#help) | показывает справку | нет |

Пароль ни в одну команду не входит: `login` спрашивает его отдельно.

## login

```sh
agentsync login [почта]
```

Входит в аккаунт. Сессия пишется в `~/.agentsync/session`. Пароль на диск не записывается. [Подробно](../start/login.md).

## push

```sh
agentsync push <ии-агент>
agentsync push agents
```

Публикует переносимую настройку одного ИИ-агента. `agents` публикует `~/.agents` без `.env`. Переменные: `AGENTSYNC_ROOT`, `AGENTSYNC_SERVER`, `AGENTSYNC_TOKEN`, `AGENTSYNC_COOKIE`. [Подробно](../config/publish.md).

## all

```sh
agentsync all
```

Публикует каждую найденную домашнюю папку ИИ-агента и `~/.agents`. Если одна публикация не проходит, остальные продолжаются. [Подробно](../config/publish.md#все-ии-агенты-сразу).

## record

```sh
agentsync record <ии-агент>
```

Записывает неизменяемый снимок в хранилище и оставляет копию в `~/.agentsync/store`. Публикацию не создаёт. [Подробно](../config/snapshots.md).

## store

```sh
agentsync store <ии-агент> [номер]
```

Без номера печатает список снимков, с номером — один снимок и сохраняет его копию локально.

## revert

```sh
agentsync revert <ии-агент>
agentsync revert agents
```

Возвращает последний снимок этого аккаунта и ИИ-агента на машине. Публикации не меняет. Переменные: `AGENTSYNC_ROOT`, `AGENTSYNC_ACCOUNT`. [Подробно](../config/snapshots.md#откатить).

## apply

```sh
agentsync apply <автор> <ии-агент>
agentsync apply <автор> agents
```

Применяет последнюю публикацию автора. Карточка ИИ-агента ложится в `~/.agents` и в домашнюю папку слиянием, `agents` точно заменяет `~/.agents`. Перед заменой пишутся снимки. [Подробно](../config/apply.md).

## skills

```sh
agentsync skills <автор> <ии-агент> --version <номер> [--global|--project] [--into <ии-агент>…] <навык>…
```

| Флаг | Значение |
|---|---|
| `--version <номер>` | версия публикации, обязателен |
| `--global` | глобальный каталог навыков |
| `--project` | каталог навыков текущего проекта |
| `--into <ии-агент>` | ИИ-агент из каталога, повторяется |
| `--skill <навык>` | ещё один навык, повторяется |

Без `--into` и без места команда спрашивает интерактивно. [Подробно](../config/skills.md).

## on

```sh
agentsync <ии-агент> on
```

Подключает ИИ-агента к `~/.agents`: ссылки на навыки, субагентов, команды и файл инструкций, перевод MCP-серверов, плагинов и хуков в его файл настроек. Вывод называет полученные и пропущенные виды. [Подробно](../config/agents.md#подключение).

## off

```sh
agentsync <ии-агент> off
```

Убирает ссылки на `~/.agents` и записи, которые вписал `on`. Собственные файлы ИИ-агента и `~/.agents` остаются. [Подробно](../config/agents.md#отключение).

## version

```sh
agentsync version
```

Печатает номер сборки; сборка без номера печатает `dev`.

## update

```sh
agentsync update [--check]
```

Скачивает сборку с адреса установки и заменяет текущий файл. `--check` только сообщает, есть ли другая сборка. [Подробно](../start/install.md#обновление).

## help

```sh
agentsync help [команда]
agentsync --help
agentsync <команда> --help
```

## Коды выхода

| Код | Значение |
|---|---|
| `0` | команда выполнена |
| `1` | команда не выполнена, причина в пояснении |
| `2` | неверные аргументы; CLI печатает справку команды |
