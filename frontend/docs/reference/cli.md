# Команды CLI

Справка в терминале: `agentsync help` — общий список, `agentsync help <команда>` — одна команда.

| Команда | Что делает | Вход |
|---|---|---|
| [`login`](#login) | входит в аккаунт | — |
| [`push`](#push) | публикует `~/.agents` (`agents`) | да |
| [`record`](#record) | записывает снимок `~/.agents` в хранилище | да |
| [`store`](#store) | читает снимки `~/.agents` из хранилища | да |
| [`revert`](#revert) | возвращает последний локальный снимок на этой машине | нет |
| [`apply`](#apply) | применяет публикацию `agents` (целиком или выбранные пути) | для своей публикации |
| [`export`](#export) | переносит переносимую настройку ИИ-агентов в `~/.agents` | нет |
| [`<ии-агент> on`](#on) | подключает ИИ-агента к `~/.agents` | нет |
| [`<ии-агент> off`](#off) | отключает ИИ-агента от `~/.agents` | нет |
| [`version`](#version) | печатает версию | нет |
| [`update`](#update) | обновляет CLI | нет |
| [`help`](#help) | показывает справку | нет |

Пароль ни в одну команду не входит: `login` спрашивает его отдельно.

## login

```sh
agentsync login [почта]
```

Входит в аккаунт. Сессия пишется в `~/.agentsync/session`. Пароль на диск не записывается. [Подробно](../start/login.md).

## push

```sh
agentsync push
```

Публикует переносимую настройку `~/.agents` (карточка `agents`) без `.env` и машинных путей. Чтобы сначала собрать настройку установленных ИИ-агентов в `~/.agents`, выполните `agentsync export`. Переменные: `AGENTSYNC_ROOT`, `AGENTSYNC_SERVER`, `AGENTSYNC_TOKEN`, `AGENTSYNC_COOKIE`. [Подробно](../config/publish.md).

## record

```sh
agentsync record
```

Записывает неизменяемый снимок `~/.agents` в частное хранилище на сервере и оставляет копию в `~/.agentsync/store`. Публикацию не создаёт. [Подробно](../config/snapshots.md).

## store

```sh
agentsync store [номер]
```

Без номера печатает список снимков `~/.agents`, с номером — один снимок и сохраняет его копию локально.

## revert

```sh
agentsync revert agents
agentsync revert <ии-агент>
```

Возвращает последний локальный снимок `~/.agents` или ИИ-агента на этой машине. Публикации на сервере не меняет. Переменные: `AGENTSYNC_ROOT`, `AGENTSYNC_ACCOUNT`. [Подробно](../config/snapshots.md#откатить).

## apply

```sh
agentsync apply <автор>
agentsync apply <автор> --version <номер> <путь>…
```

Применяет последнюю публикацию `agents` автора: точно заменяет переносимые элементы `~/.agents` и заново подключает подключённых ИИ-агентов. Перед заменой пишется локальный снимок (`agentsync revert agents`). [Подробно](../config/apply.md). С `--version` и путями кладёт в `~/.agents` только названные файлы и папки версии. [Подробно](../config/skills.md).

## export

```sh
agentsync export
agentsync export <ии-агент>…
agentsync export --only skills,mcp
agentsync export claude --plugins --hooks
```

Переносит переносимую настройку найденных (или перечисленных) ИИ-агентов в `~/.agents` в формате `agents`: навыки (`skills`), субагентов (`agents`), пользовательские команды (`commands`), файл инструкций (`instructions`), MCP-серверы (`mcp`), плагины (`plugins`) и хуки (`hooks`). С `--only` или флагами видов (`--skills`, `--agents`, `--commands`, `--instructions`, `--mcp`, `--plugins`, `--hooks`) переносятся только выбранные виды. Исходные файлы ИИ-агентов остаются на месте, перед записью `~/.agents` сохраняется в снимок (`agentsync revert agents`). Чтобы раздать элементы из `~/.agents` ИИ-агенту в его формате, запустите `agentsync <ии-агент> on`.

## on

```sh
agentsync <ии-агент> on
```

Подключает ИИ-агента к `~/.agents`: ссылки на навыки, субагентов, команды и файл инструкций, перевод MCP-серверов, плагинов и хуков в его файл настроек. Вывод называет полученные и пропущенные виды. [Подробно](../config/agents.md#подключение).

## off

```sh
agentsync <ии-агент> off
```

Убирает ссылки на `~/.agents` и записи, которые вписал `on`. Собственные файлы ИИ-агента и `~/.agents` остаются. [Подробно](../config/agents.md#отключение).

## version

```sh
agentsync version
```

Печатает номер сборки; сборка без номера печатает `dev`.

## update

```sh
agentsync update [--check]
```

Скачивает сборку с адреса установки и заменяет текущий файл. `--check` только сообщает, есть ли другая сборка. [Подробно](../start/install.md#обновление).

## help

```sh
agentsync help [команда]
agentsync --help
agentsync <команда> --help
```

## Коды выхода

| Код | Значение |
|---|---|
| `0` | команда выполнена |
| `1` | команда не выполнена, причина в пояснении |
| `2` | неверные аргументы; CLI печатает справку команды |
